## 구현 범위

| 순서 | 구현 | 범위와 남은 한계 |
| --- | --- | --- |
| 1. 진단·재생 | Android 앱 전용 2 MiB × 4개 순환 파일, 웹 IndexedDB, 선택적 위치 기록, 삭제·내보내기, 경로/보정/음성과 네이티브 GPS 재생 | 오래된 기록은 순환 삭제된다. 웹은 일반 이벤트 5,000개(각 4,096자), 경로 8개(각 300,000자)까지 저장한다. 정답 라벨 없는 기록으로 오재탐색률을 주장하지 않는다. 음성 수락은 엔진 요청 수락이며 스피커 출력 성공을 뜻하지 않는다. |
| 2. 네이티브 안내 | 서비스의 경로 스냅샷·위치 매칭·회전 음성, 오디오 포커스, 통화 중 요청 억제, 무음 저장, 음성 취소/경로 변경 순서 보호 | 기존 경로의 회전 안내다. 새 경로 계산·날씨 재분석은 앱 화면을 다시 열어야 한다. 제조사 서비스 종료·TTS 언어 미설치·블루투스 라우팅은 실기기 검증 대상이다. |
| 3. 교차로 UI | 속도/거리에 따른 자동 확대, 차로 번호 강조, 연속 회전, 확대 끄기 및 수동 조작 존중 | 제공된 차로 정보만 표시한다. 실제 표지판 이미지·차선별 GPS 판정·3D 분기 모형은 미지원이다. |
| 4. 남은 경로 재평가 | 5분 간격, 신선한 GPS와 회전까지 500 m 초과 조건에서 남은 경로의 태양/예보/ETA 재계산 | 선택 경로를 자동 변경하지 않는다. 주기적 재평가는 건물 차폐를 새로 확정하지 않으며 이를 표시한다. 예보 실패 시 맑은 하늘 가정을 표시한다. 대안 선택에는 기존 추가시간/일광 감소 기준을 유지한다. |
| 5. 무료 교통 | NYC DOT 이동시간, MassDOT 공사/통제, 신선도·형상·방향 검증, 부분 구간 ETA와 후보 비교 | 미국 일부 지역 한정. NYC의 10분 초과 관측·미래 시각·모호한 DST·잘못된 형상은 제외한다. MassDOT는 속도 데이터가 아니며 통제를 자동 회피하지 않는다. 한국/다른 국가 정체 정보는 미지원이다. |

## 자동 검증

- Node 회귀 226개 통과: 센서 신선도·시간대·방향·부분 구간 ETA, 공사 정보의 속도 미조작, 교차로/갱신 조건, 오프라인 연결·일방통행·금지 회전·사유지·장벽·통행료·평행도로·기간 만료·네이티브 경로 요청 순서를 포함한다.
- 브라우저: 루트와 `www` 각각 기존 17개 + 기록 지속/삭제 및 오프라인 워커 저장/복구 2개, 총 38개가 로컬에서 통과했다. 외부 지도·교통·경로 응답은 fixture다.
- Android: 기존 7개 + JVM 경로 매칭/회전 단계 4개. `testDebugUnitTest assembleDebug lintDebug` 통과. lint 오류 0개, 경고 19개. 실제 기기 음성이나 서비스 생존 테스트가 아니다.
- 루트/`www` 50개 파일 SHA-256 일치, 의존성 audit, 버전 증가와 기존 인증서 유지 검사.
- 통합 테스트에서 설정 패널이 검색 화면에 가려지는 문제를 발견하여 지도 복귀 버튼을 추가했다. 알림 권한 lint 오류는 기존 foreground service 알림 갱신 방식으로 수정했다.

## 무료 공개 데이터 확인

2026-10-23 UTC 실제 공개 응답을 확인했다. MassDOT 응답은 갱신 시각·작업 기간·차로 영향 정보를 포함했다. NYC 최신순 응답의 가장 최근 관측은 현지 13:57이었으며 조회 시각보다 약 2시간 이상 오래되어 실시간 ETA에서 제외됐다. 오늘 날짜라는 이유만으로 실시간이라고 표시하지 않는다. 일부 NYC 행은 좌표가 잘리고 인코딩 형상도 일치하지 않아 원본을 교차 검증하고 불일치 행을 제외한다.

도로 서버 실제 접속은 406/429 제한 응답을 반환했다. 이번 환경에서 실제 지역 자료를 내려받아 경로를 계산했다고 주장하지 않는다. 저장·복구·재탐색은 통제된 OSM fixture로 검증하며 실패 시 기존 자료를 보존한다. 다운로드는 사용자가 누를 때만 실행하고 1분 내 반복을 막는다.

- [NYC 센서 데이터](https://data.cityofnewyork.us/Transportation/DOT-Traffic-Speeds/i4gi-tjb9)
- [MassDOT 피드](https://feed.massdot-swzm.com/)

## 실제 주행 확인

조작과 기록 검토는 정차하거나 동승자가 수행한다.

| 상황 | 확인 기준과 증거 |
| --- | --- |
| 분기·연속 회전 | 예고/준비/실행·확대 시점, 차로와 표지판 일치. 진단 JSON과 안전하게 확보한 화면/음성 시각 |
| 평행도로·고가·램프·회차 | 잘못된 도로 보정과 불필요한 재탐색 여부. 실제 주행 도로를 사람이 라벨링한 기록 |
| 터널·GPS 공백 | 신호 불확실 시 잘못된 회전/도착 없음. 공백 길이와 재수신 후 정상 안내까지 시간 |
| 오프라인 이탈 | 저장 지역의 실제 우회 연결, 일방통행/금지 회전 준수. 기존·새 경로와 현장 표지판 비교 |
| 정체·일몰·날씨 | 회전 임박 시 분석 연기, 추정 시각 갱신, 임의 경로 변경 없음. 전후 시간·일광·예보 가정 |
| NYC 센서 지역 | 관측시각/반영비율, 오래된 값 제외, 예상/실제 도착시각과 ETA 오차 |
| MassDOT 작업 지역 | 주변 작업의 시각·방향·현장 비교. 표시만으로 통행 가능을 확정하지 않음 |

재생: `npm run replay:drive -- drive.json report.json`. 내보낸 JSON에는 위치·시간·경로가 있으므로 공유 전에 필요한 구간만 추린다. 자동 업로드는 없다.

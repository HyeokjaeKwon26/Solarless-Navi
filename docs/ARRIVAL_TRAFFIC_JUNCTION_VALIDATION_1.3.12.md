# 1.3.12 검증 및 현장 확인

버전: 1.3.12 / versionCode 16. 패키지와 기존 인증서는 유지합니다.

## 구현 범위

1. 공개 교통: 유효 시간, 시작/종료 시각·위치 검증, 전면 차단, 도로명, 진행방향, 8m 이내 도로 겹침 합계 40m 이상을 모두 요구합니다. 초기 미리보기와 최종 후보에서 제외합니다. 모든 후보가 차단되면 별도 오류를 표시합니다. 공사/부분 통제는 경고입니다. OSRM 후보 안에서 제외하므로 통제 없는 길이 실제로 있어도 찾지 못할 수 있습니다.
2. 차량 도착점: 사용자 확인 차량/주차장 입구, 즐겨찾기 보존, 핀 이동 시 재확인, 마지막 약 600m의 도로와 실제 경로 끝/핀 차이 미리보기. OSM 출입구를 자동 확정하거나 유료 장소 API를 사용하지 않습니다.
3. 교차로: 회전 교차로에 제공된 차로 방향만 화살표로 표시하고 유효 차로를 강조합니다. 없는 방향은 추측하지 않습니다. 현재 차로 감지는 하지 않습니다. 복잡한 분기/연속 회전 준비 안내를 앞당기고 직전 안내에서 긴 표지 목적지 목록을 생략합니다. 다음 도로명도 한국어 안내 중 영어 음성 구간으로 전달합니다. Android 백그라운드에도 적용합니다.

## 무료 데이터의 실측 한계

- [MassDOT 공식 안내](https://www.mass.gov/info-details/highway-data-for-developers), [기존 키 없는 피드](https://feed.massdot-swzm.com/massdot_wzdx_v4.1_work_zone_feed.geojson).
- 2026-10-28 04:18:29 UTC 조회: 피드 갱신 04:17:29 UTC, 총 1,355건, 활성 258건, 활성 전면 통제 25건, 네 가지 검증 필드를 모두 만족한 전면 통제 0건. 이 시점의 실피드로 실제 경로 제외가 작동했다고 주장하지 않습니다. 제외 동작은 명시적 합성 데이터로 검증합니다.
- 새 MassDOT CWZ와 GoTime 자료는 무료라도 계정/접근키가 필요합니다. 이번에는 가입·키 발급·결제 없이 기존 공개 피드만 사용합니다.
- 보스턴 전역의 실시간 정체 속도나 상용 교통 기반 ETA는 제공되지 않습니다. 기존 NYC 센서 일치 구간 외에는 기본 ETA입니다. 실제 완주 기록이 충분하지 않아 학습 ETA 보정은 추가하지 않았습니다.
- 주행 중 갱신은 기존 남은 경로 알림에 통제를 표시합니다. 이번 개선은 새 경로 검색 시 후보 제외이며, 새 통제를 발견하자마자 자율적으로 우회하는 엔진이 아닙니다. 현재 경로를 다시 검색해 확인해야 합니다.

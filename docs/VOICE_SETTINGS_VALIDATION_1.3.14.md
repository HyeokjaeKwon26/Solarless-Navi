# 1.3.14 안내 목소리 설정 검증

버전: 1.3.14 / versionCode 18. 패키지와 기존 정식 서명 인증서를 유지합니다.

## 구현

- Android 기본 TTS 엔진의 사용 가능한 한국어/영어 목소리를 표시합니다. 미설치로 표시된 음성은 제외합니다. 기기 음성을 먼저 정렬하고 인터넷 필요 여부를 표시합니다. 엔진에서 성별/인물 정보를 받지 않으므로 임의로 남성·여성·유명인 이름을 붙이지 않습니다.
- 한국어와 영어 선택은 별개입니다. 엔진 식별자와 음성 이름을 함께 저장하므로 목록 순서가 바뀌어도 다른 목소리를 잘못 고르지 않습니다. 영어권 지역(미국/영국 등)은 실제 목록에 있는 항목을 선택할 수 있습니다.
- 속도 0.50–1.50, 음높이 0.75–1.50, 0.05 단위. 두 언어 공통이며 기본값 1.00입니다. 잘못되거나 무한한 값은 기본값/허용 범위로 정규화합니다.
- Android SharedPreferences에 저장하고, 화면 안팎에서 공용 NavigationSpeech가 발화 직전에 같은 설정을 읽습니다. 한국어/영어 구간마다 해당 음성을 다시 적용합니다. PiP/화면 꺼짐에서 JS 설정 동기화를 기다리지 않습니다. 브라우저판은 별도 로컬 설정으로 Web Speech를 사용합니다.
- 이미 재생 중인 문장을 잘라 바꾸지 않고 다음 안내에 적용합니다. 음성 엔진을 바꾼 경우 실행 중인 TTS 객체를 교체하지 않으므로 앱을 다시 시작하도록 안내합니다.
- 삭제된 선택 음성은 해당 언어의 기본 음성으로 대체합니다. 선택 음성 누락을 설정 화면에 표시하고, 화면 안 안내에서는 세션 중 한 번 알립니다. 언어 데이터 자체가 없는 경우에는 기존 언어 대체/거부 처리를 유지합니다. 인터넷 필요 음성의 네트워크 단절까지 오프라인 음성으로 자동 재시도하지는 않습니다.
- 한국어/영어 미리 듣기는 화면 언어를 바꾸지 않습니다. 기존 혼합 안내 미리 듣기도 유지합니다. 주행 중, 음소거 상태, 통화/오디오 포커스 점유 시의 기존 보호 동작을 유지합니다.
- 새 마이크 권한, 음성 녹음, 유료 TTS API, 대형 음성 모델 추가는 없습니다. 인터넷 필요 목소리의 처리 방식은 사용자가 선택한 시스템 엔진에 따릅니다.

## 자동 검사

- Node 288건 통과: 설정 정규화, 안정된 음성 식별자, 잘못된 언어 선택 거부, 웹의 혼합 안내에 언어별 음성과 공통 속도/음높이 적용, 기존 안내 중단·중복 방지 포함.
- Android JVM 25건 통과: 설정 직렬화/복원, 범위/잘못된 값, 순서 변경·엔진 변경·삭제·다른 언어에 대한 선택 정책 포함. Android debug 빌드와 lint 성공(오류 0, 기존 경고 19).
- 핵심 브라우저 8건 통과(root/www): 네이티브 준비 지연, 언어별 선택/미리 듣기/초기화, 저장·재실행 복원, 누락 음성, 저장 실패 후 네이티브 상태 재조회, 320px/가로 화면, 음소거·주행 중 미리 듣기 제한.
- 첫 Android lint에서 API 24 이상 정렬 호출을 발견해 API 22 호환 호출로 수정했습니다. 작은 화면 시각 점검에서는 슬라이더 트랙과 터치 영역을 분리했습니다.
- 브라우저 검사는 네이티브 음성 엔진을 모의합니다. JVM 검사는 설정 정책을 확인하며 실제 스피커 출력, 음색, Android 서비스의 화면 꺼짐 동작을 실측한 검사는 아닙니다.
- 최종 전체 브라우저, 서명 APK, 공개 업데이트 확인 결과는 배포 후 아래에 기록합니다.

## 실제 폰 확인 목록

1. 기존 앱에서 1.3.14 업데이트 → Android 설치 승인. 즐겨찾기·단위·언어 등 기존 데이터 유지 확인.
2. 설정 → 안내 목소리에서 한국어와 영어를 서로 다른 음성으로 선택. 각 미리 듣기에서 선택한 음색인지 확인. 음성 이름/개수는 기기와 엔진별로 다릅니다.
3. 속도 0.80/1.20, 음높이 0.80/1.20 등에서 청취 차이 확인. 엔진별 구현 차이가 있을 수 있습니다. 1.00배 초기화 후 원래 목소리·속도·높이 복원 확인.
4. 한국어 안내와 Lee St., Harvard Ave. 같은 영어 도로명을 함께 미리 듣기. 한국어는 선택한 한국어 목소리, 영어 도로명은 선택한 영어 목소리인지 확인.
5. 앱 강제 종료 후 재실행, 가능하면 기기 재부팅 후 동일 설정·목소리 유지 확인. 안내를 시작한 뒤 화면 안 → PiP → 화면 끄기 → 앱 복귀에서도 음색·속도·높이가 유지되는지 확인.
6. 음악·블루투스·전화 전후 오디오 포커스와 안내 복구 확인. 화면 안/백그라운드 음성이 겹치거나 전환 시 기본 음성으로 바뀌지 않는지 확인.
7. 선택 음성을 시스템 설정에서 삭제하거나 TTS 엔진을 변경한 후 앱 재실행. 누락 표시와 같은 언어 기본 음성 대체 확인. 새 음성 설치 후 목록 새로고침/재시작 확인.
8. 기기 음성을 선택해 비행기 모드에서 안내 확인. ‘인터넷 필요’ 음성은 통신 단절 시 소리가 나지 않을 수 있으므로 별도로 확인합니다.
9. 작은 화면, 큰 글꼴, 가로 모드에서 음성 이름·슬라이더·새로고침·초기화 버튼 접근성 확인. 주행 중과 음소거 상태에서 미리 듣기가 안내를 방해하지 않는지 확인.

실제 주행 검사는 동승자가 설정을 조작하고, 교차로 안내 시점·음량·한국어/영어 전환이 운전을 방해하지 않는지 확인합니다. 연결된 ADB 기기가 없어 실제 폰 설치/오디오/화면 꺼짐 테스트는 수행하지 않았습니다.

## API 근거

- [Android TextToSpeech](https://developer.android.com/reference/android/speech/tts/TextToSpeech): 음성 목록·언어·음성 선택, 속도·음높이, 발화 큐.
- [Android Voice](https://developer.android.com/reference/android/speech/tts/Voice): 이름·언어·네트워크 요구 정보. 이름만 보고 성별이나 음질을 단정하지 않습니다.

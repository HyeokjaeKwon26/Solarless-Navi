# 1.3.23 지도 성능·주행 UX 개선

## 이번 구현 (이전 추천 4–8번)

1. **지도 표시 주기:** MapLibre의 `render` 이벤트까지의 지연을 측정한다. GPS 처리나 음성 시점을 늦추지 않고 표시 갱신 상한만 정차 약 5 Hz, 일반 주행 약 20 Hz, 회전·곡선 약 30 Hz로 구분한다. 발열/지연이 지속되면 해상도와 표시 빈도를 낮추고 안정 후 복원한다. 위치 신뢰도 변경·출발·교차로 접근 상태 변경은 표시 제한을 우회한다. 이 측정은 화면 갱신 요청부터 render 이벤트까지의 지연이며 GPU 실행 시간·실제 패널 FPS의 직접 측정은 아니다.
2. **간결한 지도 도구:** 선택 설정이며 기본은 기존 전체 버튼이다. 간결 모드에서 재중앙은 항상 보이고 나머지 지도 도구는 더보기로 펼친다. Escape와 바깥 터치로 닫으며 한글/영어·좁은 화면·가로 거치를 지원한다. 가까운 회전과 긴 직진에서 강조 크기를 달리한다. 시작 화면 계산 모델 설명은 펼쳐 보는 상세 정보로 이동했다.
3. **경로 선택 이유:** 정확히 동일한 좌표의 역할별 경로는 한 그룹에 묶고 추가 시간과 비교 가능한 햇빛 추정 차이를 먼저 표시한다. 선호도 버튼은 유지한다. 비교 모델/기상이 맞지 않으면 감소량을 표시하지 않는다. 우회 시간 초과·유효 대안 부재·분석 중을 구분한다. 기본 속도 ETA의 차이를 실제 정체 시간 절감으로 표현하지 않는다.
4. **검색·입구·도착:** 검색 목록은 전체 주소를 유지하고 거리의 직선거리 성격을 표시한다. 사용자가 직접 확인한 입구는 원래 검색 위치·전체 주소와 함께 기기에 저장한다. 같은 주소와 100m 이내 원래 위치가 일치할 때만 다시 제안하며 자동 선택하지 않는다. 검색 위치에서 500m 이내, 최대 50개·180일로 제한하고 별도 삭제를 제공한다. 저장된 확인은 현재 진입 허가/방향을 보장하지 않는다. 도착 전 500m에서는 입구 확인 상태와 경로 끝–핀 간격(25m 초과)을 표시한다.
5. **경고 설정·우선순위:** 눈부심·과속·도로 진입별 음성+화면/화면만/끔 설정을 저장한다. 회전·도착 안내, 속도 제한 표지, 경로 색상·분석 데이터는 별도다. 임박한 회전 동안 일반 경고 음성을 억제한다. 동일 눈부심 상태를 반복 발화하지 않으며 10초 이상 낮은 위험 후 재진입(최소 30초 간격), 또는 0.2 이상 위험 증가(최소 60초 간격)에서 다시 알린다. 과속 반복 간격은 30초다. 백그라운드의 기존 네이티브 회전 안내는 그대로이며 새 백그라운드 교통/눈부심 조회 엔진을 추가한 것은 아니다.

Android 주 GPS 250ms/1m 및 네트워크 위치 요청은 그대로 유지한다. 유료 API·계정·지도 DB를 추가하지 않는다. 광역 실시간 교통, Android Auto, 대규모 오프라인 지도는 이번 범위에 포함되지 않는다.

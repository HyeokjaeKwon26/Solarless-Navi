# 주행 안정성·화면·평가 개선 — 1.3.11

Android versionCode 15. 기존 패키지 `com.solaris.nav`와 정식 서명 인증서를 유지합니다.

## 4. GPS 도로 판단과 복구

- 위치 정확도에 비례해 평행·반복 구간의 매칭 모호성 기준을 강화했습니다. 정확도 35m 초과, 유효하지 않은 좌표·정확도는 매칭하지 않습니다.
- 마지막 매칭 후 15초 초과 또는 모호성 발생 시 5초 이내의 연속 두 위치로 복구를 확인합니다. 이동량·속도·정확도에 맞지 않는 점프, 중복 및 역순 위치는 확인으로 인정하지 않습니다. JS 화면 안내와 Android 백그라운드에 적용했습니다.
- 모호한 위치는 이탈 증거를 초기화합니다. 실제 이탈은 기존의 지속 시간·정확도 검증을 유지합니다. 보류된 안내가 단위 변경으로 되살아나지 않게 했습니다.
- 인접 도로의 실제 정답을 아는 기능은 아닙니다. 지도에 없는 평행도로·고가/지하 구분과 센서 오차는 실제 주행으로 확인해야 합니다.

## 5. 주행 화면과 재시작 미리보기

- 기본 집중 화면에서는 도착 예정·남은 시간·남은 거리를 동시에 표시하고 자동 페이지 교대를 멈춥니다. 설정에서 해제할 수 있습니다. 긴 경로 설명은 분석 창에서 확인합니다.
- 앱 복귀 시 지도 크기를 갱신합니다. 사용자가 지도를 옮긴 상태를 강제로 재중앙 정렬하지 않습니다.
- 활성 주행의 경로 좌표를 최대 20,000개, 12시간 한도로 기기에 보존합니다. 재시작 시 목적지가 일치하는 저장 경로를 점선으로 표시하며, 새 경로가 검증되면 교체합니다. 저장 좌표는 안내 시작 조건을 충족시키지 않습니다. 지도 타일의 오프라인 저장은 포함하지 않습니다.

## 6. 반복 가능한 주행 평가와 햇빛 예측

- 사용자가 켠 진단 기록만 집계합니다. 화면 위치 매칭/불확실/미분류, 화면 및 Android GPS 간격, 첫 검증 경로까지의 재탐색 시간, 실패·취소·미완료 요청, 완료 주행 ETA 오차를 JSON으로 제공합니다. 화면에는 주요 집계를 표시합니다.
- ETA는 출발과 도착이 모두 기록되고 도중 기록 중단·재시작이나 목적지 변경이 없을 때만 집계합니다. 정차 시간도 실제 경과 시간에 포함됩니다. 중간에 기록을 시작한 주행의 전체 ETA를 추정하지 않습니다.
- 햇빛 비교는 같은 분석 방식과 알려진 동일 날씨 모드에서만 수행합니다. 추가 소요 시간, 직사광선 노출 예상 감소, 차광 불확실성을 표시합니다. `fieldSolarBenefit`은 측정 자료가 없으므로 `null`입니다. 정답 도로 라벨이 없으면 매칭 비율을 도로 선택 정확도로 부르지 않습니다.
- `npm run replay:drive -- tests/fixtures/drive-recovery-synthetic.json report.json`으로 네트워크 없이 복구 시나리오를 반복할 수 있습니다. 예상 결과: 네이티브 위치 4개, 매칭 2개·불확실 2개, 최대 간격 20초, 재탐색 1초. 이 파일은 합성 자료이며 실제 주행 결과가 아닙니다.

## 자동 검증

- 새 회귀 테스트: 평행도로 정확도 여유, 신호 공백 후 두 위치 확인, 불가능한 점프·중복·역순 위치, 모호한 위치의 이탈 판단 보류, 미리보기 유효기간·목적지·크기 검증, 호환되지 않는 햇빛 모델 비교 제외, 완전한 주행만 ETA 집계, 기록 중단·취소 재탐색 처리.
- 브라우저: 320px 화면의 세 주행 지표, 집중 화면 설정·분석 창·뒤로가기, 서버 장애 중 점선 미리보기/안내 시작 차단, 새 경로 후 교체, 기록 요약·내보내기, GPS 복구 중 단위 변경과 회전 안내 보류. root와 APK용 www를 모두 검증합니다.
- 기존 검색·경로·GPS·지도·음성·업데이트·단위 테스트도 함께 수행합니다. 최종 실행 결과와 공개 APK 검증은 아래 배포 확인에 기록합니다.
- 로컬 Node 테스트 261개 통과. 별도 진행 중인 scene-refresh 테스트는 배포 대상 집계에 포함하지 않았습니다.
- 전체 브라우저 102개 통과. 이후 네이티브 진단 중지 시 마지막 기록 호출 완료를 기다리도록 보강했고, 관련 단위 테스트 및 root/www 기록 테스트 4개도 통과했습니다. 최종 소스 전체 검증은 배포 CI에서도 반복합니다.
- Android JVM 21개 통과, debug 빌드 성공, lint 오류 0개·기존 경고 19개. 1.3.11 / 코드 15 APK 메타데이터 확인. 의존성 감사 취약점 0개, root/www 53개 자산 일치.

## 실제 주행 확인 — 미실시

운전 중 앱 조작과 기록 확인은 동승자가 수행합니다.

1. 평행도로·고가/하부도로·반복 교차로: 도로 위치가 애매할 때 안내를 보류하는지, 잘못된 회전이나 불필요한 재탐색이 줄었는지 확인합니다. 실제 주행 도로를 별도로 기록해야 정답 비교가 가능합니다.
2. 터널·지하주차장 출구: 신호 복구 후 첫 위치만으로 안내가 튀지 않는지, 연속 신뢰 위치 후 적절히 복구되는지 확인합니다. 복구가 너무 느리면 GPS 간격·정확도와 함께 기록합니다.
3. 합법적인 경로 이탈: 새 경로가 표시될 때까지 걸린 시간, 끊긴 통신 복구, 첫 회전의 적절성을 기록합니다.
4. 익숙한 출퇴근 노선: 출발부터 도착까지 기록하고 ETA 오차를 비교합니다. 혼잡·정차·날씨를 함께 기록합니다. 상용 내비와의 차이는 동일 시간·방향 조건에서 비교합니다.
5. 햇빛 회피: 비슷한 시각·날씨의 기준/회피 경로를 비교하고 추가 시간과 실제 햇빛 구간을 별도 관찰합니다. 계산상 감소량만으로 실제 효과를 확정하지 않습니다.

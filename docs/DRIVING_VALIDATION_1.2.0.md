# SolarLess Navi 1.2.0 검증 및 실주행 확인

2026-10-23 · versionCode 3 · 패키지 `com.solaris.nav` · 1.1.0과 동일한 정식 서명키.

## 구현 범위

1. **도로 위치 판단**: 선택된 경로의 누적 거리·방향을 캐시하고 이전 위치, 시간 차이, 속도, 정확도를 함께 평가한다. 짧은 시간에 멀리 떨어진 경로 구간으로 이동하는 보정을 거절한다. 다른 경로 구간들도 비슷한 점수이면 원래 GPS 위치를 표시하고 회전 안내를 멈춘다. 반대 방향 증거도 기존 이탈 판정에 넣는다(3개 이상, 2초 이상; 재탐색 간격 8초 이상). 15초 이상 위치가 끊겼을 때는 오래된 진행 제한을 해제한다.
2. **회전·분기 안내**: 직선거리 대신 경로상 거리를 사용한다. 회전 지점은 경로별로 한 번 계산하고, 동일 교차점을 재방문할 때는 순서와 제공자 누적 거리를 사용해 구별한다. 예고/준비/근접 안내는 속도에 따라 각각 250–1,000m / 90–400m / 20–60m 범위에서 바뀐다. 이 값은 초기 정책이며 실주행 보정이 필요하다. 180m 이내 연속 회전, 제공되는 도로명·번호·방면·출구, 기존 차로 정보를 사용한다. 원본 데이터가 없으면 추정해 만들지 않는다.
3. **장시간 주행**: 음성 취소를 직렬화하고 취소된 음성이 웹 음성으로 뒤늦게 재생되는 경쟁을 막는다. 회전 안내 후 6초간 일반 음성 알림을 억제하며 도착·이탈 알림은 우선 처리한다. 기기 상태를 주행 중 최대 30초에 한 번 읽고 시스템 절전/발열 단계 moderate 이상/비충전 배터리 15% 이하에서 기존 절전 렌더링을 적용한다. 잔량 때문에 켜진 모드는 20% 초과 시 해제한다. GPS 수집 간격은 줄이지 않는다. 유효 위치 수신 중 목적지·모드·통행료 설정을 최대 30초에 한 번 저장한다. 복구 기록은 12시간 이내이며 미래 시각·범위 밖 좌표를 거절한다.

진단 기록은 사용자가 시작할 때만 메모리에 저장한다. 배터리 잔량·배터리 온도·시스템 발열 단계·절전 여부를 추가했다. 배터리 온도는 CPU 온도가 아니다. 기존 14,400개 샘플 제한 때문에 4Hz에서는 약 1시간 이후 추가 샘플이 버려진다. 장거리 측정은 동승자가 구간별로 저장하고 새 기록을 시작한다. 위치 기록의 자동 업로드는 없다.

## 자동 검증 범위

합성 좌표·서비스 응답과 테스트용 음성을 사용하며 실측 주행 결과가 아니다. 배포 워크플로는 단위·브라우저·Android 검사를 모두 통과한 경우에만 APK를 게시한다.

- 교차·평행 구간 모호성, 불가능한 진행, GPS 공백 후 재획득, 북쪽/반대 방향, 헤어핀 거리, 동일 교차점 재방문.
- 속도별 안내, 경계 진동 시 중복 억제, 연속 회전, 음성 충돌, 중단 후 반복, 늦은 네이티브 실패 및 취소 순서.
- 복구 기록 검증, 배터리 정책, 지도·자유 주행·오프라인 복구·업데이트 회귀 검사.
- root/www 일치, Android 단위 테스트·컴파일·Lint, 배포 APK 버전·패키지·서명·해시.

## 남은 한계

선택된 경로와 GPS의 일치 여부를 판단하는 개선이다. 주변 도로 전체의 연결 관계·고도·차선 위치를 이용하는 상용 지도 매칭은 아니다. 동일 방향의 가까운 평행도로 또는 고가/지하를 확정할 수 없다. 위치가 계속 애매하면 안내가 대기할 수 있다. GPS 공백 동안 관성항법으로 이동을 추정하지 않는다.

기존 화면 숨김에 따른 음성 중단·복귀를 보강했지만 통화 오디오 포커스, 제조사 백그라운드 제한, Bluetooth 출력은 기기 확인이 필요하다. 프로세스 종료 중 무중단 안내, 통신 없이 새 경로를 계산하는 오프라인 라우팅 엔진, 실시간 교통·차로 데이터의 완전성은 이번 범위에 포함하지 않는다.

기기 상태 API: [Android PowerManager](https://developer.android.com/reference/android/os/PowerManager#getCurrentThermalStatus()), [BatteryManager](https://developer.android.com/reference/android/os/BatteryManager). API 29 미만은 발열 단계가 제공되지 않는다. 배터리·시스템 절전 정보는 제공될 때만 사용한다.

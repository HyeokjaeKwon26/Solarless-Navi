# 1.3.22 렌더링·GPS 구독·기록 저장 최적화

## 구현 범위

1. **렌더링:** 경로 선분을 64개 단위로 나눴다. 먼 경로의 GeoJSON은 분석 결과가 바뀔 때 전송하고, 현재 구간만 차량 위치에 맞춰 갱신한다. 좌표 단순화나 위치 샘플 생략은 하지 않는다. 현재 진행 구간 이전의 경로는 필터로 숨긴다. GPS 불확실 상태에서는 두 경로 소스를 모두 숨기며 기존 색상·점선 기준을 유지한다. HUD 치수는 ResizeObserver로 무효화해 다시 측정하고 GPS·3D 버튼은 상태 변경 시에만 갱신한다. 조감도 중에는 숨겨진 Leaflet 차량 마커 갱신을 생략한다.
2. **GPS:** Android GPS 250ms/1m 요청과 네트워크 위치 2초/10m 요청을 유지한다. 주 GPS의 요청 주기를 늦추는 변경은 현장 지연 검증 전이므로 적용하지 않았다. 정확도 25m 이내의 신선한 네이티브 GPS가 3회 이상, 최소 500ms에 걸쳐 연속 확인될 때만 중복 WebView 구독을 일시 중지한다. 새 샘플 없이 750ms 신선도 한계를 넘기면 타이머로 복구하며, 저정확도·위치 서비스 오류에는 즉시 복구 경로를 실행한다. 실제 콜백 시점은 OS의 스케줄링에 영향을 받는다. 1Hz 등 충분히 촘촘한 위치를 제공하지 않는 기기에서는 기존 이중 구독을 유지한다. 화면 복귀 시에도 먼저 보조 구독을 복구한 뒤 다시 검증한다.
3. **저장:** 현재 위치는 메모리와 안내 파이프라인에 즉시 전달한다. 디스크 복구 사본은 2초 간격으로 저장하며 화면 복귀 시 메모리의 최신 위치를 우선 사용한다. 네이티브 진단 샘플은 최대 1초 또는 64KiB 단위로 묶고 큰 단일 이벤트는 바로 쓴다. 중요 이벤트·내보내기·기록 종료·Activity 일시 중지·서비스 종료 때 저장한다. 웹 기록도 위치 샘플을 한 IndexedDB 트랜잭션으로 묶으며 내보내기·삭제 전에 반영한다. 기록은 기존 동의 설정을 따르고 자동 업로드하지 않는다.

## 자동 검증 근거

- 5,000개 선분의 경로에서 구간 경계 전후의 좌표·색상·불확실성 정보가 기존 경로와 동일한지 비교했다.
- 실제 MapLibre 브라우저 테스트에서 120회 위치 갱신 중 먼 경로 전송은 1회이고 현재 경로 데이터는 64개 선분 이내인지 확인했다. 이는 작업량 검사이며 폰의 FPS·배터리 절감률 측정은 아니다.
- GPS 전환·수신 중단·저정확도·서비스 중단·재수신, 기존 불확실 위치 차단·경로 복구를 검사했다.
- 웹에서 40개 샘플이 1개 쓰기 트랜잭션에 저장되고 내보내기 순서와 삭제 결과가 보존되는지 검사했다.
- Android에서 250ms 간격 40회 입력에 복구 저장 허용은 5회인 것을 검증했다. 실제 SharedPreferences 디스크 쓰기 횟수는 OS 병합 정책에 따라 다르다.
- 진단 기록의 UTF-8·순서·파일 회전·최대 용량·버퍼 비우기·저장 실패 처리를 JVM 테스트로 검사했다.

최종 전체 테스트 및 공개 APK 검증 결과는 배포 후 기록한다.

## 실제 폰·주행 비교

자동 테스트는 실제 GPS 정확도와 음성 안내 시점을 보증하지 않는다. 같은 기기·밝기·음성·지도 모드·충전 조건으로 1.3.21과 비교하며 다음을 확인한다. 운전 중 조작은 동승자가 수행한다.

| 상황 | 확인 항목 | 통과 기준 |
|---|---|---|
| 정차 후 출발·시내 연속 회전·고속도로 출구 | 위치 지연, 회전 음성 시점, 잘못된 재탐색 | 이전 버전보다 늦어지거나 악화되지 않음 |
| 터널·실내·GPS 끄기/켜기 | 위성 버튼, 보조 위치 복구, 잘못된 도로 붙음 | 불확실 위치로 안내·도착을 확정하지 않고 수신 회복 후 정상 복귀 |
| 화면 꺼짐·PiP·전화 후 복귀 | 음성 중단/중복, 최신 위치, 3D↔2D 마커 | 오래된 복구 사본으로 위치가 되돌아가지 않음 |
| 긴 경로·색상 재평가·회전 경계 | 경로선 연결·사라짐·색상·HUD 여백 | 경로 누락·단절·가림 없이 기존 의미 유지 |
| 진단 기록 켜짐/꺼짐·즉시 내보내기·삭제 | 마지막 샘플과 순서, 삭제 후 재등장 | 정상 종료/내보내기에서는 누락 없이 반영, 삭제 기록은 재등장하지 않음 |
| 30분 이상 동일 조건 실행 | 배터리 소모·발열·프레임 지연·위치 지연 | 정확도/안내 지연 악화 없이 개선 여부를 실측 |

갑작스러운 프로세스 종료·전원 차단에서는 마지막 복구용 위치 약 2초 및 진단 샘플 약 1초가 저장되지 않을 수 있다. OS가 작업을 지연하거나 저장 오류가 나면 더 길어질 수 있다. 정상 주행 안내는 디스크 저장 완료를 기다리지 않는다.

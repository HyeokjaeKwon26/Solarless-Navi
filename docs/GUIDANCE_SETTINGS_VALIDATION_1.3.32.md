# 1.3.32 음성 신뢰성·편한 경로·설정 정리

## 구현 범위

### 1. 음성 재생 및 청취 결과

- Android TTS의 요청, onStart, onDone, onError를 구분한다. 첫 시작 콜백까지의 지연, 시작 콜백 없는 완료, 취소·시간 초과를 기록한다. 시작 전 4초, 시작 후 완료까지 60초 한도를 적용해 오래된 대기열과 오디오 포커스를 정리한다. 콜백은 실제 스피커 음성이나 발음 품질의 증거가 아니다.
- 현재 회전 식별자가 바뀌면 기존 회전 안내를 취소한다. JS 비동기 stop 대기 및 네이티브 브리지에서 늦게 도착한 이전 회전 요청도 검사한다. 복귀 시 현재 회전을 다시 전달한다. 전경과 배경은 기존 단일 TTS 소유권을 유지한다.
- 진단은 사용자가 버튼을 눌렀을 때 읽는다. 세션 내 최근 이벤트 48개만 메모리에 보관하고 문장·위치·음성 ID를 저장하지 않는다. 기존 명시적 주행 기록 기능과 별개다.
- 비교 청취 결과는 엔진·보고된 목소리·속도·음높이 조합별 최대 40개를 로컬에 저장한다. 사용자 판정이며 자동 음질 평가가 아니다. 새 엔진/모델 및 인터넷 음성을 추가하지 않았다. 기존 LocaleSpan 방식의 실제 발음과 같은 화자 유지 여부는 폰 청취가 필요하다.

### 4. 운전하기 편한 경로

- 기존 simple 모드를 보강한다. 제공된 경로 후보의 회전, 유턴, 분기, 급회전 및 120m 미만 간격의 연속 동작을 비교한다. 거리 정보가 없으면 연속 회전을 추정하지 않는다.
- 유턴이 늘어나는 후보는 제외한다. 개선 점수당 최대 30초, 전체 최대 2분, 최단시간 대비 20%, 사용자 우회 한도를 모두 지킨다. 재탐색도 동일 제한을 적용한다. 충분한 개선이 없거나 안내 단계가 없으면 기본 최단 경로를 유지한다.
- 명시적인 폭 태그가 양쪽 후보 전체 구간에 있을 때만 폭 비교에 반영한다. 일반 OSRM 응답에는 폭이 없으므로 현재 대부분 경로에서 폭 평가는 미확인이다. 이름 없는 길이나 주거 도로를 좁은 길로 가정하지 않으며 추가 데이터 다운로드를 하지 않는다.
- 설정과 경로 비교에서 회전 복잡도 및 시간 차이를 보여준다. 실시간 교통·도로 난이도 완전 파악이나 모든 가능한 경로 탐색을 의미하지 않는다.

### 5. 설정 화면

- 자주 쓰는 설정/전체 설정과 경로·화면/단위·목소리·업데이트 바로가기를 추가했다. 기본은 자주 쓰는 설정이며 마지막 보기 선택을 기억한다.
- 경로 선호와 통행료, 단위/화면, 음성 선택/속도/미리 듣기, 업데이트에 쉽게 접근한다. 음성은 접었다 펼친다. 세부 음성 비교·진단, 시뮬레이션, 오프라인 및 실험 도구는 전체 설정에 남긴다.
- 기존 DOM 컨트롤을 이동하여 설정값과 이벤트를 보존한다. 위치 수신·지도 프레임·안내 거리·회전 시점은 바꾸지 않았다. 새 폴링이나 백그라운드 네트워크 요청은 없다.

## 실제 폰·주행 확인 목록

1. 정차 상태에서 기본/선택 목소리로 같은 한영 문장을 듣고 결과를 저장한다. 앱 재시작 후 같은 조합의 결과가 유지되는지 확인한다. 발음이 어색하면 엔진명과 실제 선택 음성을 함께 기록한다.
2. 음성 재생 진단의 시작/완료 수와 실제 소리를 비교한다. 무음·통화·블루투스 연결/해제 때 콜백만으로 소리가 났다고 판단하지 않는다.
3. PiP와 화면 꺼짐, 다시 앱으로 복귀한 뒤 현재 회전 안내가 이어지는지 확인한다. 가까운 두 회전, 회전을 지나친 상황, 재탐색에서 이전 회전이 뒤늦게 나오지 않는지 확인한다.
4. 동일 출발/도착지에서 최단시간과 편한 경로를 비교한다. 화면의 추가 시간·회전 차이와 실제 동작이 일치하는지 확인한다. 도로 폭·실제 통행 가능 여부·체감 난이도는 현장에서 확인한다.
5. 기본 설정에서 경로·목소리·단위·업데이트 접근, 전체 설정 전환, 큰 시스템 글꼴·가로 화면·뒤로 가기를 확인한다.
6. 기존 서명 앱 위에 설치하여 설정 유지와 다음 업데이트 확인을 검사한다. 같은 조건 30~60분 주행으로 배터리/발열을 비교한다. 이번 작업에서는 실제 폰 설치·청취·주행·전력 측정을 하지 않았다.

운전 중 조작과 청취 비교는 동승자가 맡거나 정차 후 진행한다.

# 1.3.17 눈부심 표시·경로 선택 검증

버전 1.3.17 / versionCode 21. 기존 com.solaris.nav 패키지와 정식 서명키를 유지한다.

## 문제와 수정

사용자는 345 Harvard Street → 84 Gerry Road 주행에서 눈부신 도로로 안내된 사례와 실제 눈부심이 없는데 주황색으로 표시된 사례를 보고했다. 스크린샷 시각은 17:17·17:21이다. 촬영 날짜·선택 모드·GPS/후보 로그가 없어 당시 현상을 완전히 재현한 것은 아니다. 사진에는 실제 전방 장면이 없다.

1. 이전 실시간 배너는 경로 예보와 별도로 Bird 맑은 하늘 조건을 사용했다. 정밀 분석을 원래 geometry에 매핑할 때도 차폐는 갱신하면서 glareRisk는 간이 분석 값을 유지했다. 매핑 시 원래 도로 방향과 정밀 일사·차폐로 눈부심을 다시 계산하며 평균도 다시 합산한다.
2. 주행 경로선, 화면 배너, PiP, 음성 경고는 동일한 구간 스냅샷을 사용한다. GPS 처리 중 최대 60초 간격으로 현재 시각·예상 통과 시각을 재계산한다. 새 남은 경로 예보나 정밀 분석이 오면 다음 GPS 처리에서 갱신하며, 같은 geometry/구간에서도 기존 Leaflet 레이어 색상과 점선을 갱신한다. 새 예보가 실패한 경우 이전 예보로 조용히 돌아가지 않는다.
3. 예보 수신 후 30분이 지나거나 해당 위치/시각을 덮지 못하면 맑은 하늘 가정으로 구분한다. 차폐는 원래 계산 시각과 예상 통과 시각 차이가 2분 이내일 때만 재사용한다. 갱신 시각으로 차폐 수명을 연장하지 않는다. 유효시간은 보수적 소프트웨어 정책이며 현장 검증된 물리적 보증이 아니다.
4. 눈부심 추정값 >0.45라도 기상 예보 또는 수치 차폐 정보가 없으면 노랑 점선과 ‘차폐/기상 미확인’을 사용한다. 주황색과 강한 눈부심 음성은 둘 다 있는 높은 추정값에만 사용한다. 노랑 점선은 눈부심이 없다는 뜻이 아니다. 자유주행은 경로 차폐 자료가 없으므로 높은 맑은 하늘 추정이 나와도 미확인 표시를 사용한다.
5. 고정 거리·서쪽·우회·쾌적한 그늘·안전 구간을 임의로 말하던 음성을 제거했다. 현재 구간의 눈부심 가능성만 말한다. 실제 회전 안내 거리·단위는 유지한다. 계기 지수는 주행 전 경로 평균, 주행 중 현재 구간이며 확률로 표현하지 않는다.

## 경로 선택

- 기존 평균 추정값 외에 >0.45인 구간의 누적 초와 최장 연속 초를 합산한다. 비용은 `Σ(추정값 × 구간 초) + 강한 추정 구간 초 + 최장 연속 초`다. 실험적 선택 비용으로 ETA나 실제 눈부심 확률이 아니다.
- 후보는 비용이 감소해야 하며, 평균값 0.05 이상 개선 또는 평균값 악화 0.02 이내이면서 강한 구간 누적/최장 연속 시간이 30초 이상 감소해야 한다. 기존 최단시간 대비 35% 한도 및 사용자 0/2/5/10분 한도를 유지한다.
- 정밀 분석 대상으로 고르는 순서와 정밀 분석 후 역할 선택에도 같은 비용을 사용한다. 비교 분석 단계·기상 단계가 맞는 후보를 사용하는 기존 정책을 유지한다.
- 카드에 강한 눈부심 가능 구간의 누적/연속 추정 시간을 표시한다. 최단시간과 같으면 비교 후보 없음, 사용자 추가 시간 한도, 35% 우회 한도, 또는 개선/우회 조건 미충족으로 설명한다. 모든 도로망을 탐색했다거나 다른 우회로가 없다는 주장은 하지 않는다.
- 순간 눈부심을 계기로 자동 재탐색·자동 우회하는 기능은 이번 범위에 포함하지 않는다. 나무·차량·실제 구름·앞유리·사용자의 시력·차광판을 측정하지 않는다. 유료 API나 현장 카메라 입력을 추가하지 않았다.

## 자동 검증

- 새 단위 검사는 평균 개선이 0.05보다 작아도 30초의 강한 눈부심을 없애는 후보, 우회 한도 초과, 동일 누적/서로 다른 연속 시간, 예보 강도 변화, 차폐 만료, null 차폐, 정밀 결과 매핑을 포함한다.
- 브라우저 검사는 같은 경로에서 강한 일사 → 약한 일사 → 차폐 미확인 → 그늘로 조건을 바꾸고 실제 SVG 색·점선, 화면 배너, 음성 호출이 함께 바뀌는지 확인한다. 320px·가로 화면 범례도 확인한다. 모두 명시적 합성 입력이며 현장 재현이 아니다.
- 최종 전체 검사와 배포 결과는 아래에 기록한다.

## 실제 폰·주행 확인 — 미실시

1. 기존 정식 앱에서 업데이트 알림 → APK 다운로드 → 설치. 즐겨찾기·언어·음성·단위·경로 선호 설정 유지.
2. 345 Harvard Street → **84** Gerry Road를 같은 날짜/시간 조건에 가깝게 비교. 촬영 날짜·시각·선택 모드·추가 시간 한도·버전과 실제 눈부심 여부를 기록한다. 과거 94 Gerry Road와 구분한다.
3. 맑은 도로, 건물 그늘, 나무 그늘, 흐린 날에서 실제 시야와 주황/노랑 점선/보라를 비교한다. 범례와 ‘미확인’ 문구가 실제로 읽히는지 확인한다.
4. 정체나 정차로 ETA가 2분 이상 밀릴 때 오래된 그늘을 확정적으로 유지하지 않는지, 새 예보·구간 이동 후 경로색과 배너가 함께 바뀌는지 확인한다.
5. 인터넷 끊김·복귀, 30분 이상 오래된 예보, GPS 불량·복귀에서 미확인 표시와 기존 회전 안내 유지 여부를 확인한다.
6. 주황 구간 음성이 실제 구간과 일치하고, 노랑 점선에서 강한 눈부심을 확정해 말하지 않는지 확인한다. 근거 없는 고정 거리·서쪽·우회 도로 문구가 나오지 않아야 한다.
7. PiP, 화면 끄기/복귀, 차량 블루투스에서 회전 안내와 설정 유지. 백그라운드 Android 서비스가 새로운 기상·차폐 분석을 계속 수행하는 기능은 추가하지 않았으며, 복귀 후 GPS에서 분석이 갱신된다.
8. 최단시간/역광 회피 및 0/2/5/10분 한도에서 선택 경로·이유·강한 눈부심 지속 추정과 실제 체감을 비교한다. 실제 회피 효과와 오경보율은 아직 측정하지 않았다. 주행 중 조작·기록은 동승자가 수행한다.

## 로컬 검사 결과

- Node 311건 통과. 기존의 맑은 하늘 전용 구현을 문자열로 검사하던 테스트를 제거하고 예보·차폐 동작 검사 및 브라우저 통합 검사로 대체했다. 기존 음성 테스트의 임의 거리 기대값도 현재 구간 예측 문구 검증으로 변경했다.
- 새 브라우저 통합 검사와 좁은/가로 범례 검사 통과. 노랑 점선과 미확인 배너 캡처를 확인했다. 전체 root/www 회귀 검사는 배포 전후 기록에 추가한다.
- Android JVM 27건 통과. debug APK 빌드 성공. lint 오류 0건, 기존 경고 19건. npm audit 취약점 0건.
- root/www 자산 61개 SHA-256 일치. 기존 버전 대비 versionName/versionCode 증가 및 패키지·인증서 유지 검사 통과.
- 합성 구간 1,000개의 주행 추정 갱신은 이 데스크톱에서 54ms였다. 폰 성능·발열·배터리 측정은 아니다.
- ADB 연결 기기 없음. 실제 설치·시야·블루투스·주행 검증은 미실시다.

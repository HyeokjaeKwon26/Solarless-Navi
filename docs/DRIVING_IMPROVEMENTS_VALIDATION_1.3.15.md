# 1.3.15 GPS·경유 비교·개인 ETA 검증

버전 1.3.15 / versionCode 19. 기존 패키지 `com.solaris.nav` 및 정식 인증서를 유지합니다.

## 1. GPS 이동 흐름

- 화면 및 Android 백그라운드 안내에 최근 최대 8초·32개 승인 위치를 사용합니다. 원좌표의 누적 이동량, 위치 정확도, 경로 진행 거리의 일관성을 검사하고 후보 점수에도 이동 차이를 반영합니다.
- 보고 속도가 커져 직전 위치 검사만 통과하더라도 최근 이동량으로 설명할 수 없는 뒤쪽 반복 구간 이동은 보류합니다. 공백·경로 교체 뒤 오래된 기록을 재사용하지 않고 시간 역전·중복도 거부합니다. 이동 불일치 뒤에는 연속 두 위치 확인으로 복구합니다. 불확실한 위치로 재탐색 증거를 쌓지 않습니다.
- 선택한 경로 안에서의 시간 연속성 보강입니다. 모든 주변 도로의 지도 매칭, 고가/지하 위치 판별, 새로운 관성항법은 아닙니다. 실제 오판 감소율은 미측정입니다.

## 2. 경로 주변 장소 우회 비교

- 기존 주변 검색 후 최대 3곳만 계산합니다. 직접 경로 1회와 경유 경로 최대 3회입니다. 기존 1분 간격 제한을 유지하고 HTTP 429 이후 추가 요청을 중지합니다. 각 경로 요청 제한 시간은 10초입니다.
- [OSRM 데모 서버 정책](https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server)에 맞춰 기존 경로 탐색과 새 우회 비교가 같은 앱 내 대기열에서 최소 1초 간격으로 요청을 시작합니다. 취소된 대기 요청은 전송하지 않습니다. 여러 기기/사용자를 합산하는 중앙 제한기는 아니며 서비스 가용성은 보장되지 않습니다.
- 출발점·목적지·통행료 회피 조건을 같게 두고 주행 중이면 출발 방향도 전달합니다. 직접 경로 대비 추가 시간·거리, 경유 경로 전체 유턴 수를 표시합니다. 음수 차이는 0으로 표시합니다. 현재 선택한 햇빛 회피 경로 대비 차이가 아니라 동일 시점 직접 경로 대비 차이입니다.
- 유효한 경로·구간 수·좌표·거리·시간과 지점의 도로 스냅 거리(60m 이하)를 검사합니다. 기존 공개 통제 판정에서 확인된 차단 경로는 유효한 견적으로 표시하지 않습니다. 실제 영업·차량 입구·사유지 최신 상태는 미확인입니다.
- 계산된 후보를 추가 시간, 유턴 수 순으로 정렬합니다. 미계산/실패 장소는 뒤에 두고 ‘우회 시간 미확인’을 표시합니다. 오프라인에서는 저장 목록만 사용합니다.
- 새 검색, 경로/목적지/통행료 설정 변경, 안내 시작/종료, 차량의 100m 이상 이동, 2분 경과 후의 결과로 경유지를 선택하지 못하게 합니다. 선택 뒤 기존 도착점 확인 및 안내 경로 검증을 다시 거칩니다.
- 기본 OSRM 도로 속도 추정이며 정차 시간과 실시간 정체는 반영하지 않습니다. 공개 서비스 제한과 OSM 누락으로 실패할 수 있습니다. 유료 API·새 계정·지도 DB 번들은 추가하지 않았습니다.

## 3. 개인 ETA

- 기본 꺼짐입니다. 별도의 동의 설정과 기기 내 이력을 사용합니다. 진단 기록 삭제와 ETA 이력 삭제는 별개입니다.
- 정규화한 경로 좌표의 식별자, 출발 시각·요일·현지 2시간대·시간대 오프셋, 기본 예상 시간, 실제 경과 시간을 저장합니다. 서버 업로드는 없습니다. 식별자는 익명성 보장이 아닙니다. 이 기능은 주소 이름이나 GPS 시계열을 추가 저장하지 않습니다.
- 최대 100회, 90일 이내 기록을 사용합니다. 만료 기록은 다음 앱 시작/저장 때 정리합니다. 같은 경로·요일·2시간대·시간대 오프셋의 완료 기록 5회 이상이 필요해 여러 주가 걸릴 수 있습니다.
- 마지막 두 기록은 앞선 기록으로 구한 보정의 검증에 사용합니다. 이 두 기록의 절대 오차 합이 기본 예측보다 10% 이상 낮아야 하고, 비율의 중앙절대편차가 0.25 이하여야 합니다. 최종 중앙값 계수는 0.8~1.5, 변화 3% 미만이면 미적용입니다. 실제 정확도 향상률이나 예측 구간을 주장하지 않습니다.
- 화면 시간 표시만 보정하고 경로 순위·태양 노출 계산은 유지합니다. 출발 시 계수를 고정하고 재탐색 시 해제합니다. 카드·주행 요약에 개인 기록 보정임을 표시합니다. PiP는 같은 화면 ETA를 쓰며 별도의 네이티브 ETA 엔진은 추가하지 않았습니다.
- 실시간 속도가 반영된 경로, 오프라인 경로, 시간 시뮬레이션은 보정 대상에서 제외합니다. 주행 시작 전에 켠 경우만 학습합니다. 중단/재탐색/경로 변경, 60초 초과 승인 위치 공백, 5분 초과 저속 정차는 제외합니다. 도착 전 15초 이내 승인 위치와 최소 3개 위치가 필요합니다. 앱 종료 후 학습 세션은 복원하지 않습니다.
- 60초 미만/6시간 초과 주행, 실제/예상 비율 0.5~3 밖은 저장하지 않습니다. 정차도 실제 시간에 포함되지만 5분 초과 정차가 있으면 전체 주행을 제외합니다. 배터리 제한으로 JS 위치 처리가 오래 멈춘 주행도 제외될 수 있습니다.
- 끄면 수집과 보정을 멈추고 기록은 삭제 버튼으로 지웁니다. 저장 실패 시 성공한 것처럼 설정/목록을 바꾸지 않습니다. 켜기/삭제 후 현재 주행에는 새 보정을 시작하지 않으며 다음 주행부터 적용합니다.

## 자동 검사

- Node 299건 통과: 이동 흐름·시간 역전·공백, 우회 순위·요청 상한·429·오래된 응답·통제·스냅 거리, 공용 요청 대기열 간격·취소, ETA 표본·검증 오차·만료·동의·삭제·저장 실패·중단/경로 변경/정차 제외.
- Android JVM 27건 통과, debug 빌드 성공, lint 오류 0 / 기존 경고 19. 짧은 반복 구간 점프 거부, 연속 복구, 고빈도 정상 진행 포함.
- 핵심 브라우저 8건 통과(root/www): 동의/재실행/저장 실패, 이력의 카드·HUD 적용/삭제, 우회 비교 및 도착점 확인, 기존 경유지 보존. 320px·가로 화면 배치와 캡처를 점검했습니다.
- 위치·이력·장소·경로 응답은 합성 자료입니다. 실제 접근성·교통 정확도·개인 ETA 개선율 측정이 아닙니다. 전체 회귀와 최종 소스 CI, 공개 APK 결과는 아래에 추가합니다.
- 요청 간격 보강 전 로컬 전체 브라우저 134건 통과(5.8분). 간격 보강 뒤 영향받는 경로 검사와 최종 소스 전체 CI를 다시 확인합니다.
- 간격 보강 후 선택 검사에서 10건 통과, 장소 관련 4건 실패를 조사했습니다. 동일 경로의 장면 분석 갱신까지 검색을 취소하던 객체 참조 비교를 경로 좌표 식별자 비교로 수정했고 기존 경유 검사 2건이 통과했습니다. 새 견적 검사의 요청 카운터가 기존 경로 탐색까지 포함하던 부분을 분리한 뒤 나머지 2건도 통과했습니다. 최종 Android debug 빌드에서 버전 1.3.15 / 19를 확인했습니다.
- root/www 59개 자산 SHA-256 일치, npm audit 취약점 0건. ADB 연결 기기 없음.
- 최종 상태 전환 보강 후 root/www의 안내 시작 중 지연 견적 폐기 및 정상 견적 순위 검사 4건 통과. 이전 소스의 배포 실행은 게시 전에 취소하고 최종 커밋으로 다시 검사합니다.
- GitHub 전체 검사에서 134건 통과·오래된 GPS 미리보기 검사 2건 실패를 확인했습니다. 요청 대기열로 늦어진 경로 분석 응답이 새 GPS 대기 중 경로선을 다시 그리는 경쟁 상태였습니다. 차량 스냅, 동적 경로선, 경로 렌더링 모두에서 현재 세션의 신뢰 위치 대기 상태를 확인하도록 수정했습니다. 실패한 소스의 APK 게시 단계는 실행되지 않았습니다.
- 위 수정 후 오래된 GPS/선택 주소/낮은 GPS 정확도, 이탈·통신 복구·GPS 공백·차로 표시, 지연 장소 응답·우회 비교 검사 16건이 root/www에서 모두 통과했습니다(2.0분).

## 공개 경로 API 확인 (2026-10-28)

이전 문서의 주소 대표 좌표인 Harvard Street 학교(42.3449239, -71.1236747) → Gerry Road(42.3006881, -71.1570098)를 사용했습니다. 공개 OSRM은 8,931.6m / 744.2초, 도로 스냅 거리 44.28m / 9.38m를 반환했습니다. 반환된 경로의 중간 좌표를 시험 경유점으로 삼아 새 비교 코드가 동일 시간·거리와 유턴 0회를 정상 처리하는 것을 확인했습니다. 실제 주유소/주차장 입구나 현장 운행 시간이 아니라 공개 응답 형식·연결 확인입니다. 사용자 폰의 현재 GPS를 읽은 것이 아닙니다.

## 실제 폰·주행 확인 목록 — 미실시

1. 1.3.14 → 1.3.15 앱 내 업데이트. 즐겨찾기·음성·언어·단위·저장 자료 유지 확인.
2. 화면 안내 → PiP → 화면 끄기 → 복귀. 평행도로·짧은 반복 구간·급회전에서 잘못된 위치 이동/회전 안내, 재탐색 횟수·복구 지연을 기록합니다. 실제 도로를 별도 표시해야 정답 비교가 가능합니다.
3. 안전한 경로 이탈에서 실제 이탈을 오래 숨기지 않고 재탐색하는지 확인합니다. 터널 출구·정차 후 출발·GPS 복구도 포함합니다.
4. 주변 주유소/주차장 두 곳의 추가 시간·거리·유턴, 중앙분리대와 실제 차량 입구를 비교합니다. 도착점·영업 여부는 현장 확인이 필요합니다. 서버 제한/비행기 모드에서 미확인 표시도 확인합니다.
5. ETA 학습을 켜고 동일 경로·요일·시간대에 정상 완료 주행을 누적합니다. 중간 종료·긴 정차·목적지 변경·재탐색은 기록 수에 추가되지 않아야 합니다. 기록 수, 재실행 보존, 끄기/삭제를 확인합니다.
6. 보정 전후 기본 예상 시간·표시 예상 시간·실제 시간을 비교합니다. 합성 학습 이력을 실제 성능 증거로 쓰지 않습니다. 기록 부족/변동이 큰 노선에서는 기본 ETA를 쓰는 것이 정상입니다.
7. 큰 글꼴·세로/가로·작은 화면과 보정 표시, 마일/km·한국어/영어를 확인합니다. 주행 중 조작·기록은 동승자가 수행합니다.

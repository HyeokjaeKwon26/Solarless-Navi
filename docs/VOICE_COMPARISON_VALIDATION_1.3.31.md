# 1.3.31 기존 엔진의 기본·선택 음성 비교

## 확인한 코드 차이와 확인하지 못한 원인

이전 버전은 한 목소리 모드에서 영어 도로명과 한국어 문장을 String 하나로 합쳐 영어 구간 정보를 잃었다. 기본 음성에도 setLanguage를 중복 호출하고 이미 선택된 기본 목소리를 setVoice로 재지정했다. 언어별 모드에서는 한국어·영어에 서로 다른 선택 음성을 사용하는 것이 코드상 명확하다.

이 동작이 사용자의 폰에서 들린 발음 차이의 직접 원인인지는 미확인이다. 폰 연결이 어려워 실제 엔진, 기본/선택 음성의 청취 비교, 화자 동일성 검증은 수행하지 않았다. 모든 기기용 음성이 다국어 발음을 지원한다고 가정하지 않는다.

[Android setLanguage](https://developer.android.com/reference/android/speech/tts/TextToSpeech#setLanguage(java.util.Locale))는 언어의 기본 음성을 설정한다. [LocaleSpan](https://developer.android.com/reference/android/text/style/LocaleSpan)은 텍스트 구간의 언어를 표현하고, [SynthesisRequest](https://developer.android.com/reference/android/speech/tts/SynthesisRequest#getCharSequenceText())는 CharSequence를 엔진에 제공한다. 이 API 문서는 특정 엔진이 LocaleSpan을 반영하거나 동일 화자를 유지한다고 보장하지 않는다. 이 변경은 엔진에 전달할 정보를 보존하는 조치이며, 실제 발음 결과는 별도 검증 대상이다.

## 변경

- SpeechPlan은 영어 구간의 UTF-16 범위를 유지한다. NavigationSpeech는 LocaleSpan을 붙인 한 문장을 기존 TTS에 전달한다. 앱 차원의 영어 목소리 전환이 없다.
- SpeechDispatch가 전경·PiP·화면 꺼짐의 공통 호출 순서를 담당한다. 한 목소리는 setLanguage 1회, 실제로 다른 목소리일 때만 setVoice 1회다. 기본 음성이 이미 맞으면 setVoice를 생략한다.
- 설치된 기기용 음성만 허용하고 모든 문장 부분의 음성을 먼저 확인한다. 네트워크 기본 음성으로 우회하거나 일부 안내만 큐에 넣는 것을 방지한다.
- Android 첫 업그레이드 시 한 번 한 목소리 모드로 이전한다. 음성 ID, 속도·음높이·메모는 보존한다. 사용자가 이후 명시적으로 언어별 모드를 고르면 그대로 저장한다.
- 기본/선택 비교는 동일한 한국어·영어 예문, 속도·음높이, 언어 구간 정보, 한 목소리 모드를 사용한다. 저장값을 바꾸지 않는다. 기본을 누르면 한국어 기기용 기본값, 선택을 누르면 저장된 한국어 음성을 사용한다.
- 비교 정보는 요청 음성과 TTS의 getVoice 보고값이다. 실제 들린 음색의 증거는 아니다. 안내 문장·음성 녹음·위치를 저장하거나 업로드하지 않는다.
- 비교 미리 듣기는 전경·안내 종료 상태에서만 허용한다. UI 음소거/주행 가드 및 네이티브 전경/주행 가드가 있다. 오류는 화면에 표시한다.
- 기존 웹/레거시 대체 엔진에는 Android LocaleSpan 지원을 주장하지 않는다. 새 TTS 엔진·모델·지도 자료와 GPS/안내 주기 변경은 없다.

## 실제 폰 확인 순서

1. 설치 후 설정 → 안내 목소리에서 한 목소리 모드와 기존 음성·속도·음높이 보존을 확인한다.
2. 한국어 미리 듣기 아래 ‘기본 목소리로 비교 듣기’와 ‘선택한 목소리로 비교 듣기’를 각각 끝까지 듣는다. 예문은 ‘잠시 후 Lee Street에서 우회전하세요. 이어서 Harvard Avenue 방면으로 좌회전하세요.’다.
3. 기본과 선택의 한국어 화자, Lee Street/Harvard Avenue의 영어 발음, 도로명 전후 화자 변화를 각각 기록한다. 비교 정보에 표시된 엔진/요청/보고 음성을 함께 확인한다. 두 버튼이 같은 음성이면 비교 대상이 기본으로 선택된 상태인지 확인한다.
4. 기본은 자연스럽고 선택만 어색하면 그 선택 음성의 언어 처리 차이를 우선 의심한다. 둘 다 개선되지 않으면 LocaleSpan을 해당 엔진이 무시하는지 추가 확인해야 한다. 자동 테스트 통과만으로 해결 판정하지 않는다.
5. 실제 안내에서 같은 선택을 확인하고 PiP·화면 꺼짐·복귀·블루투스에서도 화자가 바뀌거나 안내가 중복/누락되지 않는지 확인한다. 운전 중 조작하지 않는다.
6. 비행기 모드 미리 듣기, 기존 앱 위 설치/데이터 유지, 시스템 TTS 엔진·목소리 변경 후 앱 재시작을 확인한다.

## 자동 검증

검사 및 공개 APK 검증 결과는 배포 완료 후 아래에 기록한다. 실제 음성 청취, 실제 주행, 배터리 측정은 수행하지 않았다.

- 로컬 Node 383개, Android JVM 42개 통과. Android debug 빌드 및 lint 통과(오류 0, 기존 경고 19).
- 변경 음성 화면 브라우저 검사 root/www 총 14개 통과. 320px 및 가로 화면 버튼 경계·44px 높이, 저장 유지, 음소거·주행 가드, 실패 표시 확인.
- 합성 주행 회귀 게이트 2개 통과, 의존성 감사 취약점 0, root/www 자산 85개 SHA-256 일치.
- 모의 엔진 테스트는 기본/선택 호출 차이, 한 번의 재생, 영어 구간 UTF-16 범위, 선택 불가/네트워크 기본값/엔진 거절을 검사한다. 실제 Android 엔진의 음성 출력 검사는 아니다.
- 최초 브라우저 비교 검사에서 설정 화면을 닫는 테스트 동작이 잘못돼 시간 초과했다. 실제 UI의 출발지/목적지 변경 버튼으로 진입하도록 테스트를 수정한 뒤 14개가 통과했다.

## 1.3.30 배포 시도에서 확인한 검사 문제

1.3.30(3be9dfc)의 main/배포 CI는 음성 검사를 포함해 브라우저 110개씩 통과했으나 지도 캐시 1개가 실패하여 APK를 공개하지 않았다. 야간 자동 테마가 /styles/dark를 저장했는데 테스트는 /styles/liberty를 고정해서 조회한 문제다. 모든 외부 응답은 테스트 fixture이며 실제 지도 서버 장애가 아니다.

1.3.31은 현재 렌더러의 theme URL 및 해당 캐시 저장 완료를 확인한 뒤 네트워크 차단/동일 데이터 재사용을 검사한다. 검사 생략이나 임의 재시도가 아니며 앱 지도 캐시 코드 변경은 없다. 기존 1.3.30 태그는 이동하지 않았다.

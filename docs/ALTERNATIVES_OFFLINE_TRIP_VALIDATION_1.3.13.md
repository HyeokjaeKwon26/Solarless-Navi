# 1.3.13 검증 및 현장 확인

버전 1.3.13 / versionCode 17. 기존 패키지와 배포 인증서를 유지합니다.

## 구현 범위와 한계

### 4. 대안 경로

- 기본 탐색 예산은 기존대로 유지합니다. 사용자가 주행 전에 ‘대안 더 찾기’를 누르면 직접 경로와 최대 네 개의 우회 지점 요청을 사용합니다. 1분 간격 제한, 중복 후보 제거, 기존 통제·통행료·불필요한 유턴 필터를 유지합니다.
- 실제 후보의 시간/거리, 유턴, 복잡한 분기, 이름 없는 도로 길이, 기준 경로와의 대략적인 중복률을 표시합니다. 겹침은 최대 100개 표본 점과 기준 경로의 25m 이내 여부로 추정하므로 정확한 공유 거리 비율이 아닙니다.
- 햇빛 감소는 같은 분석 방식과 날씨 조건에서만 비교합니다. 도로 폭·현장 통행 가능 여부나 실제 햇빛 회피 성능을 검증한 수치가 아닙니다. OSRM이 반환하지 않는 대안까지 보장하지 않습니다.

### 5. 선택형 소규모 오프라인 자료

- APK에는 지역 지도 DB를 넣지 않습니다. 사용자가 선택한 한 지역(3×3 km 또는 6×6 km)을 IndexedDB에 별도로 저장하며, 새 지역을 저장하면 이전 지역을 교체합니다. 자동 다운로드는 없습니다.
- JSON 저장 자료 상한은 12 MiB(12,582,912 bytes), 요소 상한은 80,000개, 검색 목록 상한은 20,000개입니다. Android가 표시하는 앱 데이터 용량은 저장소 메타데이터/캐시 등으로 이 수치와 다를 수 있습니다. 실행 중 그래프 메모리 사용량에 대한 12 MiB 제한은 아닙니다.
- 응답 크기를 스트리밍 중 검사하고 이전 자료는 새 자료 검증·저장이 완료된 뒤 교체합니다. SHA-256으로 저장 자료의 우발적 손상을 검사합니다. 삭제 시 진행 중 다운로드가 자료를 되살리지 않도록 취소 세대를 적용합니다. 기존 해시 없는 도로 팩은 호환성을 위해 허용합니다.
- 7일 유효한 저장 도로와 이름/주소/주유소/주차장만 사용합니다. 번호 주소는 집 번호와 도로명을 함께 확인합니다. OSM 주소 누락은 보간하거나 임의의 유사 장소로 대체하지 않습니다.
- 도로선·이름·장소 점을 앱에서 직접 그립니다. 일반 지도 타일·건물 지도·전국 DB를 저장하지 않습니다. [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/)은 공용 타일 서버의 오프라인 대량 다운로드를 허용하지 않습니다.
- 저장 범위 밖 또는 연결·제한 조건을 확인할 수 없는 경로는 거부합니다. 기존 일방통행·회전 제한·사유지/조건부 접근 제외를 유지합니다. ‘단순한 경로 선호’는 회전과 service 도로에 선택 비용을 부여하지만 ETA에 비용을 더하지 않습니다. 실제 운전 난이도나 도로 폭 검증은 아닙니다.
- 인터넷 없이 새 지역 검색, 실시간 교통/날씨, 누락 도로 보완은 할 수 없습니다. 이 기능은 완전한 오프라인 내비게이션의 대체가 아닙니다.

### 6. 휴대전화 거치 사용

- 시스템 음성 인식 Activity로 en-US/ko-KR 목적지를 입력합니다. 앱이 마이크를 직접 녹음/저장하거나 새 마이크 권한을 요청하지 않습니다. 시스템 제공자는 인터넷이나 별도 권한을 요구할 수 있습니다. 입력 결과는 검색 후보와 도착점 확인을 거쳐야 하며 자동 출발하지 않습니다.
- 경유지는 새 현재 목적지로 두고 원래 목적지와 나머지 목적지를 보존합니다. 최대 3개의 다음 목적지, 12시간 보존이며 중복/잘못된 좌표를 거부합니다. 다음 구간은 안내 종료 후 사용자가 선택합니다. 전체 다중 경유 최적화·합산 ETA·자동 구간 전환은 구현 범위 밖입니다.
- 연료/주차 검색은 남은 경로의 최대 10km에 대해 2km 간격 최대 6개 표본, 각 750m 주변을 사용자 요청 때 조회합니다. 표본 사이 누락이 가능하며 우회 주행 거리나 영업/입구를 검증하지 않습니다. 1분 간격 제한, 오래된 경로 응답 거부, 저장 자료 대체를 적용합니다.
- Android Auto는 미포함입니다. [Android 공식 차량 테스트 안내](https://developer.android.com/training/cars/testing)는 실제 헤드유닛용 Car App Library 앱의 신뢰할 수 있는 설치 출처를 요구하며, Android Auto의 알 수 없는 소스 옵션은 해당 앱에 적용되지 않는다고 설명합니다. 개발용 DHU 테스트와 일반 GitHub APK 설치를 상용 차량 지원으로 표현하지 않습니다. 유료 API/계정 등록/결제를 진행하지 않았습니다.

## 자동 검증

- Node 283건 통과. 번호 주소 오인 방지, 범위·잘못된 좌표, 전방 장소 거리 제한, 경유지 순서/중복/만료, 단순 경로 선택과 ETA 분리, 비교 가능성 검사 포함.
- 핵심 브라우저에서 선택 저장·재실행 후 오프라인 검색/경로, 과대 자료 거부·이전 자료 보존, 해시 손상 거부, 삭제 중 다운로드 완료 경쟁, 시스템 음성 입력 결과 확인/취소/오류, 경유 후 최종 목적지 보존, 주유소 경유, 320px 버튼 배치를 검증했습니다. 실제 음성 인식과 공개 지도 응답은 모의합니다.
- Android Java 컴파일, JVM 단위 검사, debug APK 빌드, lint 성공. 실제 시스템 음성 화면이나 차량 테스트를 수행했다는 뜻은 아닙니다.
- 로컬 전체 브라우저 118건 중 112건 통과. 저장 영역 선택 UI로 변경되어 이전 버튼 문구를 기대하던 단위 검사 6건을 새 메뉴 검사로 갱신했습니다. 해당 6건과 서버 제한/저장 자료 없음 검사 2건을 재실행해 8건 모두 통과했습니다. 최종 소스의 전체 120건은 GitHub 배포 검사에서 다시 실행합니다.
- Android JVM 22건, lint 0 errors / 기존 19 warnings. npm audit 취약점 0건, root/www 웹 자산 56개 SHA-256 일치. ADB 연결 기기는 없습니다.

## 실제 폰에서 확인

- 기존 배포 앱에서 업데이트 확인 → 다운로드 → Android 설치 승인. 즐겨찾기/언어/단위/설정 유지.
- 다운로드 전후 Android 앱 저장 공간 비교. 3×3 / 6×6 km 저장, 용량 초과 실패 후 이전 자료 유지, 삭제 후 저장 공간 회수. DB/캐시 때문에 화면 숫자와 Android 숫자가 정확히 같지는 않을 수 있습니다.
- 지역 저장 후 비행기 모드, 앱 강제 종료/재실행. 저장 주소 검색과 지역 내 경로선/도로 이름, 저장 범위 밖 경로 거부, 7일 만료 안내.
- 시스템 음성 인식 설치 유무, 영어/한국어, 취소, 네트워크 끊김, 긴 주소, 블루투스 연결. 인식이 틀렸을 때 후보와 도착점에서 수정 가능 여부.
- 작은 화면·큰 글꼴·가로 화면에서 비교 상세, 경유지/다음 목적지, 언어 선택, 저장 용량/삭제 버튼 접근성.
- 경유지 도착 후 현재 안내 종료, 다음 목적지 선택, 재실행 후 남은 목록과 새 목적지 선택 시 목록 초기화. 주행 중 경유 추가가 시작되지 않는지 확인.

## 실제 주행에서 확인

- 동승자가 조작/기록하고 현장 표지와 진입 제한을 따릅니다.
- 익숙한 두 경로에서 기본/추가 대안의 실제 차이, 유턴/분기 수, 주행 시간 비교. 이름 없는 도로를 좁은 길로 단정하지 않습니다.
- 저장된 안전한 지역에서 통신을 끊은 뒤 GPS·경로 이탈·재탐색·도로 이름·일방통행/회전 제한을 대조합니다. 오류 시 현장 도로 규칙을 우선하고 재탐색 결과를 기록합니다.
- 주유소/주차장 경유 시 반대편 차로, 중앙분리대, 실제 차량 입구, 영업 여부, 예상 밖 우회가 있는지 확인합니다. 표시된 ‘경로와 거리’는 실제 우회 거리와 다릅니다.
- 경유지별 안내와 최종 목적지 보존, GPS 흔들림/통신 복귀, PiP·백그라운드·전화 후 복귀를 확인합니다.

## 공개 서비스 점검

- 이번 직접 Overpass 요청은 HTTP 429(요청 제한)를 반환했습니다. 재시도를 반복하지 않았고 실제 데이터 다운로드 성공으로 기록하지 않습니다. 합성 응답으로 저장·검색·경로 동작을 검증했습니다. 앱에는 서버 요청 제한과 기존 자료 유지 안내를 추가했습니다. 무료 서버 사정에 따라 새 지역 저장과 주변 장소 조회가 일시적으로 실패할 수 있습니다.

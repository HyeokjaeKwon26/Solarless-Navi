SolarLess Navi 1.3.15

GPS 이동 흐름 검증, 경로 주변 장소의 실제 우회 비교, 선택형 개인 ETA 보정을 추가했습니다.

- GPS는 직전 위치뿐 아니라 최근 최대 8초의 이동 기록도 비교합니다. 가까운 반복 구간으로 진행 거리가 갑자기 뛰는 판단을 보류하고 연속 위치 확인 후 복구합니다. Android 백그라운드 안내에도 적용했습니다.
- 경로 주변 주유소·주차장 중 최대 3곳의 직접/경유 경로를 비교합니다. 추가 주행 시간 순으로 표시하고 추가 거리·유턴 수도 보여줍니다. 기본 도로 속도 기준이며 정차 시간·영업 여부·실제 차량 입구는 미확인입니다.
- 설정 → 내 주행 기반 도착시간에서 기기 내 학습을 켤 수 있습니다. 기본은 꺼짐입니다. 같은 경로·요일·2시간대 완료 기록이 5회 이상이고 최근 기록 검증에서 오차가 감소할 때만 보정합니다. 실시간 교통 예측이 아닙니다.
- 보정은 경로 카드와 남은 시간·도착시간에 표시합니다. 경로 선택·햇빛 분석의 계산값은 유지합니다. 실시간 속도가 반영된 경로와 시간 시뮬레이션에는 보정을 적용하지 않습니다.
- 이력은 최대 100회이며 90일 이내 자료만 사용합니다. 기기에만 저장하고 삭제할 수 있습니다. 중단·재탐색·긴 위치 공백·5분 초과 정차가 있는 주행은 학습에서 제외합니다.

기존 서명키를 유지합니다. 앱에서 업데이트 확인 → 다운로드 → Android 설치 확인으로 업데이트할 수 있습니다.

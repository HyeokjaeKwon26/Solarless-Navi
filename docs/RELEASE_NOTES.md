SolarLess Navi 1.2.0

1.1.0과 같은 정식 서명키를 사용합니다. 정식 1.1.0 사용자는 앱의 업데이트 확인에서 기존 데이터를 유지하며 Android 설치 확인으로 업데이트할 수 있습니다. 구서명/디버그 APK에서 정식 앱으로 최초 전환할 때만 삭제 후 재설치가 필요합니다.

- 최근 경로 진행 위치와 GPS 방향·속도·정확도·시간을 함께 사용해 도로 위치를 보정합니다. 판단이 모호하면 강제로 도로에 붙이지 않고 회전 안내를 대기합니다. 반대 방향 이동도 연속 증거를 확인한 뒤 재탐색합니다.
- 회전까지의 거리를 도로 경로를 따라 계산하고 속도별 음성 예고, 가까운 연속 회전, 제공되는 출구 번호·도로 번호·방면·차로를 안내합니다.
- 동일 회전 반복과 음성 취소 경쟁을 줄이고, 회전 직후 일반 알림이 음성을 덮어쓰지 않도록 했습니다.
- Android 절전·발열 단계·배터리 상태에 따른 자동 절전과 수동 절전 설정 저장을 추가했습니다.
- 주행 중 목적지·경로 모드·통행료 설정을 주기적으로 저장합니다. 복구를 선택하면 현재 위치에서 경로를 재계산하며 안내 시작은 직접 누릅니다.
- GPS가 끊기거나 도로 위치가 불확실하면 이전 회전·차로 표시를 숨깁니다. 경로 계산 캐시와 기록 비활성 시 불필요한 계산도 개선했습니다.

실제 주행 확인 항목과 남은 한계는 [1.2.0 검증 문서](https://github.com/HyeokjaeKwon26/Solarless-Navi/blob/main/docs/DRIVING_VALIDATION_1.2.0.md)에 별도로 정리했습니다. 상용 지도 수준의 고가·평행도로 식별이나 실제 차량에서의 안내·발열 성능을 검증한 릴리스는 아닙니다.

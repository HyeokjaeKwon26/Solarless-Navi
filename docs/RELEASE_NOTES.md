SolarLess Navi 1.3.9

한국어 안내 중 영어 도로명은 영어 음성으로 읽습니다. Lee St. → Lee Street, Harvard Ave. → Harvard Avenue처럼 도로 약어를 풀어 읽으며, 거리·회전 지시는 한국어를 유지합니다. 앱 화면과 Android 백그라운드 안내에 모두 적용했습니다. 설정에서 안내 음성을 미리 들어볼 수 있습니다. 영어 음성이 설치되지 않은 경우 기본 안내 언어로 대체하며 화면에 설치 안내를 표시합니다. 실제 발음과 오프라인 음성 지원은 기기의 TTS 엔진에 따라 다릅니다.

검색·최근 장소·저장된 즐겨찾기로 경로를 찾기 전에 전체 주소, 출발지와의 직선거리, 지도 핀을 확인합니다. ‘도착점 조정’으로 핀을 옮길 수 있습니다. 집·회사 및 새 즐겨찾기 등록도 첫 검색 결과를 자동 저장하지 않고 사용자가 후보를 선택하고 지도에서 확인한 뒤 저장합니다. 가까운 위치의 서로 다른 가게를 하나의 검색 결과로 합치지 않도록 했습니다.

사용자가 직접 조정한 핀은 마지막 이름 있는 도로로 임의 단축하지 않습니다. 차량 경로의 실제 도착점과 선택한 핀이 25m 이상 떨어진 경우 거리 차이와 출입구 확인 안내를 표시합니다. 지도 데이터만으로 차량 출입 가능 여부를 확정하지는 않습니다.

진행 방향을 알 수 없는 상태를 북쪽(0도)으로 잘못 해석하던 경로 요청을 수정하고, 방향이 다른 경로가 같은 캐시를 재사용하지 않도록 했습니다. 다른 후보보다 느리거나 길지 않으면서 유턴·짧은 무명 구간이 더 적은 경로가 있으면 복잡한 후보를 걸러냅니다. 필요한 유턴이 있는 유일한 경로나 시간·거리 이점이 있는 후보는 유지합니다. 경로 카드에는 유턴 수와 실제 교통 반영 범위를 표시합니다. 광역 실시간 교통 데이터가 새로 추가된 것은 아닙니다.

Android 백그라운드에서도 가까이 이어지는 회전을 함께 안내합니다. 언어 전환 중 전화·음소거·새 경로가 끼어들면 남은 이전 음성을 취소합니다. 웹 진단 기록 저장 완료를 기다린 뒤 재시작할 수 있도록 저장 완료 반환값도 추가했습니다.

1.3.5 이상에서는 앱의 업데이트 확인 → 다운로드 → 설치로 업데이트할 수 있습니다. Android의 설치 허용 및 최종 설치 확인은 직접 진행해야 합니다. 1.3.4 이하에서는 APK를 직접 내려받아 덮어 설치해 주세요. 기존 정식 배포와 동일한 서명키를 유지합니다.

실제 폰 확인: 한국어·영어 음성 전환 간격, 영어 음성 미설치·오프라인 상태, Bluetooth·전화 중단/복귀, PiP·화면 꺼짐, 앱 내 업데이트와 설정 유지.
실제 주행 확인: 도착 핀과 차량 출입구의 일치, 재탐색 시 진행 방향, 유턴·대안 경로의 적절성, 안내 시점과 실제 ETA 오차. 운전 중 조작은 동승자가 진행해 주세요.

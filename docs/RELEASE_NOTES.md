SolarLess Navi 1.3.24

주행 판단·재탐색·검색 복구·교차로·ETA·서비스 복구·현장 평가를 개선했습니다.

1. 화면과 Android 백그라운드가 같은 합법적 도로 연결 정보를 사용하고, 공유 GPS 시나리오로 판단과 복구 시점을 검사합니다.
2. 이탈 재탐색에서 우회 한도와 햇빛 선호를 지키며 초기 유턴이 없는 후보를 비교합니다. 새 경로의 계산·실패·완료 상태를 표시합니다.
3. 눈부심 관찰을 태양 고도·방향·차폐·기상 조건별로 검토하고 날짜를 분리해 기준값 후보를 평가합니다. 자료가 부족하면 보정하지 않습니다.
4. 주소 검색 실패 뒤 지역 추가 검색, 최근 주소, 지도 도착점 확인으로 이어갈 수 있습니다.
5. 가까운 복잡한 교차로에 선택 경로의 작은 개요를 표시합니다. GPS가 불확실하면 숨기고, 좁은 화면의 도구는 공간에 맞춰 접습니다.
6. 같은 시간대의 과거 주행 범위를 표시하고 최근 구간 지연만 제한적으로 반영합니다. 실시간 교통 예측으로 표시하지 않습니다.
7. 검색·경로·네이티브 경로 전송의 장애를 분리하고 재시도 간격을 관리합니다. GPS와 회전 안내 주기는 유지합니다.
8. 선택한 주행 진단에서 충전·밝기·온도·렌더 지연을 기록하고 이전 JSON과 비교할 수 있습니다. 실제 배터리 절감량과 눈부심 정확도는 현장 측정 전입니다.

기존 정식 서명키와 설정을 유지합니다. 유료 API·전국 지도 DB를 추가하지 않았습니다.

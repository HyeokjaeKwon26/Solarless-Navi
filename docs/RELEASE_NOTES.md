SolarLess Navi 1.3.2

정식 1.1.0~1.3.1과 같은 서명키를 사용합니다. 기존 앱을 삭제하지 않고 업데이트할 수 있습니다.

- 첫 목적지 입력 화면에서 우측 상단 설정 버튼으로 바로 들어갑니다. Free drive를 먼저 켤 필요가 없습니다. 좁은 화면에서도 설정 버튼의 44px 터치 영역을 확보합니다.
- 오프라인 도로·주행 진단·업데이트 버튼의 높이, 모서리, 글꼴, 색상과 포커스 표시를 통일하고 기능별로 묶었습니다. 교차로 확대는 다른 옵션과 같은 토글을 사용합니다. 버튼은 선택한 한국어/영어로 표시합니다.
- 앱을 새로 실행할 때마다 버전을 한 번 확인합니다. 이전의 6시간 확인 간격은 제거했습니다. 새 버전이 있으면 ‘업데이트 다운로드’ 또는 ‘일단 계속 사용’을 선택할 수 있습니다. 계속 사용을 선택하면 그 실행 중에는 자동으로 다시 띄우지 않으며 다운로드/설치를 시작하지 않습니다.
- 업데이트 확인은 Free drive/경로 안내 중에도 동작합니다. 수동 확인은 확인 중·최신 버전·실패 상태를 팝업으로 표시합니다. 다운로드·설치는 안내 종료 후 진행하며, 주행 중 자동 팝업은 종료 후로 미룹니다.
- 확인 중에도 버튼을 누르면 현재 진행 상태가 보입니다. 연결 또는 설치 버전 조회가 응답하지 않으면 시간 초과와 재시도를 제공합니다. Android 뒤로가기로 업데이트 팝업을 닫을 수 있습니다.
- 주행 진단 기록 버튼이 비동기 작업 후 잘못된 이벤트 대상을 참조하던 문제를 수정했습니다.

기존 앱에서 업데이트 확인이 막힌 경우 Free drive를 종료한 뒤 확인하거나 이 릴리스의 APK를 직접 받아 덮어 설치하세요.

실제 폰 확인: 시작 화면에서 설정 진입, 글자 크기 확대 시 버튼 배치, 새 버전 안내에서 계속 사용, APK 설치 권한 승인 및 기존 데이터 유지. 실기기 설치·주행 검증은 별도입니다.

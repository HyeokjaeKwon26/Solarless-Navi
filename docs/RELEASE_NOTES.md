SolarLess Navi 1.3.20

무료로 사용할 수 있는 주행 검토·지도·도착 안내 기능을 개선했습니다.

1. 주행 진단에서 저장한 기록 또는 JSON 파일을 지도와 시간 슬라이더로 재생합니다. 화면 GPS와 Android 백그라운드 GPS를 구분하며, 같은 입력 파일의 버전별 재계산 결과를 비교하는 도구를 추가했습니다.
2. 저장한 도로 영역에서는 주변 도로의 방향·연결 관계를 함께 비교합니다. 평행도로 선택이 모호하면 확정 안내를 보류하며, Android 백그라운드에도 주변 도로 검사를 적용합니다.
3. 굽은 길과 정차 시 조감도 카메라를 조절하고 정차 중 방향 흔들림을 줄입니다. 발열 또는 지속적인 화면 지연이 감지되면 해상도·갱신 빈도를 낮추고 안정화 후 복원합니다.
4. 주행 후 기록의 시각·지점을 골라 실제 눈부심 여부를 저장하고 오탐·누락을 검토합니다. 기기에 최대 200건·90일 보관하며 자동 업로드나 자동 보정은 하지 않습니다.
5. 목적지 확인 화면에서 OSM의 차량·주차장 입구 후보를 찾아 선택할 수 있습니다. 지도상 차량 접근과 일방통행 방향을 확인하되, 현장 출입 가능 여부는 직접 확인해야 합니다.
6. 지도 중심 구간의 정밀 자료 출처·OSM 원본 날짜·저장 상태를 확인하고 해당 구간만 다시 받을 수 있습니다. 전체 자료를 다시 받거나 APK에 넣지 않습니다.

기존 정식 서명키를 유지합니다. 주변 도로 검사는 선택 저장한 영역에서 작동하며, 무료 공개 서비스의 자료 범위와 가용성 제한이 있습니다. 실제 주행 정확도 향상·발열 감소는 현장 검증 전입니다.

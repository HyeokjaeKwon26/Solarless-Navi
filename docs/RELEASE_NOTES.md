SolarLess Navi 1.3.19

조감도 주행 화면과 교차로 안내 화면을 추가했습니다.

- 주행 시 도로·경로선·차량을 같은 MapLibre 지도에 표시합니다. 기본 기울기는 50°이며, 교차로 접근 시 32°로 낮추고 다음 회전 지점이 보이도록 확대 수준을 조절합니다.
- 지도 2D/3D 버튼으로 전환하고 선택을 기억합니다. 경로 미리보기는 2D로 표시합니다. 절전·PiP·화면 숨김·위성 지도와 지도 오류 시 기존 2D 화면을 사용합니다.
- 교차로에서 도로명·출구 번호를 크게 표시하고, 가까운 다음 회전의 화살표를 함께 보여줍니다. GPS가 불확실하면 교차로 강조를 보류합니다.
- 가로 거치 화면은 회전 안내·도착 정보·제어 버튼을 나눠 배치해 지도 공간을 확보했습니다.
- MapLibre 6 지원 여부 확인 방식을 수정해 지원 기기에서 벡터 지도를 사용할 수 있게 했습니다.

기존 무료 지도 서비스를 사용하며 지도 DB나 3D 건물 모델을 APK에 추가하지 않았습니다. 실제 폰에서 프레임·발열·배터리와 주행 중 위치 정렬은 별도 확인이 필요합니다. 기존 정식 서명키를 유지합니다.

SolarLess Navi 1.3.13

대안 경로 비교, 선택형 지역 저장, 음성 목적지 검색과 경유지 기능을 추가했습니다. 지도 데이터를 APK에 포함하지 않습니다.

- 실제 찾은 후보의 시간·거리, 유턴·복잡한 분기, 이름 없는 도로 길이, 경로 중복과 예상 햇빛 감소를 비교할 수 있습니다. 주행 전에 추가 후보를 요청할 수 있으며, 무료 서비스 요청량을 제한합니다. 없는 대안을 만들거나 도로 폭을 추정하지 않습니다.
- 오프라인 자료는 사용자가 선택한 3×3 km 또는 6×6 km 지역만 별도로 저장합니다. 직렬화한 자료는 최대 12 MiB이고 한 지역만 유지합니다. 다운로드하지 않으면 지도 저장 공간은 추가로 쓰지 않습니다. 저장 용량 표시·삭제·손상 검사를 제공하며, 용량 초과 시 이전 자료를 유지합니다.
- 저장된 OSM 도로·주소·주유소·주차장을 7일간 이용합니다. 인터넷이 없어도 저장 주소 검색과 지역 내 경로 계산, 도로 이름 표시가 가능합니다. 지도 타일은 저장하지 않으며, 전국 오프라인 지도나 완전한 주소 DB가 아닙니다. 선택 시 오프라인 경로에서 회전과 service 도로가 적은 후보를 선호합니다.
- Android 시스템 음성 입력으로 영어/한국어 목적지를 검색합니다. 인식된 주소는 검색 결과와 지도에서 직접 확인해야 합니다. 제공자에 따라 인터넷과 시스템 음성 서비스가 필요합니다.
- 경유지를 추가해 원래 최종 목적지를 보존합니다. 최대 세 개의 다음 목적지를 남길 수 있고, 현재 안내를 종료한 뒤 ‘다음 목적지’로 진행합니다. 전체 경유 여정의 최적화나 합산 ETA는 제공하지 않습니다.
- 경로 앞쪽 최대 약 10 km의 표본 구간에서 무료 OSM 주유소·주차장을 조회하고 경유지로 추가할 수 있습니다. 실제 우회 시간·영업·차량 진입 가능 여부는 별도 확인이 필요합니다.

Android Auto는 이번 GitHub APK에 포함하지 않았습니다. 실제 차량용 Car App Library 앱은 신뢰할 수 있는 설치 경로 등의 별도 배포 조건이 있어 APK 설치만으로 지원을 보장할 수 없습니다. 이번에는 휴대전화 거치 사용을 개선했습니다. 유료 API 가입이나 결제는 없습니다.

기존 정식 배포와 같은 서명키를 사용합니다. 앱의 업데이트 확인 → 다운로드 → Android 설치 확인으로 업데이트할 수 있습니다.

SolarLess Navi 1.3.23

지도 성능·주행 화면·경로 설명·도착점·경고 설정을 개선했습니다.

1. 실제 지도 render 이벤트까지의 지연과 발열 상태를 반영하고, 정차·직진·교차로에 따라 표시 갱신 빈도를 조절합니다. 주 GPS 요청 주기와 회전 안내 처리는 유지합니다. 먼 경로 표시 필터의 문법 오류도 수정했습니다.
2. 설정에서 간결한 지도 도구를 켜면 재중앙은 항상 표시하고 나머지는 더보기로 펼칩니다. 시작 화면의 계산 방식 설명은 상세 정보로 옮겼습니다.
3. 같은 경로의 선호도 옵션을 한 그룹으로 묶고 추가 시간·햇빛 추정 차이·우회하지 않은 이유를 표시합니다. 비교 자료가 부족하면 감소량을 단정하지 않습니다.
4. 직접 확인한 차량 입구를 기기에 기억하고 같은 주소 검색에서 다시 제안합니다. 자동 선택하지 않으며 삭제할 수 있습니다. 도착 전에는 입구 확인 상태와 경로 끝–핀 간격을 표시합니다.
5. 눈부심·과속·도로 진입별 음성+화면/화면만/끔을 설정합니다. 회전 안내를 우선하고 같은 눈부심 상태의 반복 경고를 줄였습니다.

기존 정식 서명키를 유지합니다. 유료 API·지도 DB를 추가하지 않았습니다. 실기기 배터리·발열·주행 지연 개선량은 측정 전입니다. 저장한 입구는 과거 사용자 확인이며 현재 통행 허가나 진입 방향을 보장하지 않습니다.

SolarLess Navi 1.3.4

배터리가 부족해 자동 절전으로 전환된 뒤 일반 모드로 돌아가지 못하던 문제를 수정했습니다.

- 절전 버튼은 실제 화면 상태를 기준으로 전환합니다. 자동 절전 중에도 한 번 누르면 일반 모드로 돌아갑니다.
- 수동으로 일반 모드를 선택하면 이번 앱 실행 중에는 자동 검사가 절전을 다시 강제하지 않습니다. 앱을 새로 실행하면 자동 판단을 다시 적용합니다.
- 충전기 연결·해제 및 Android 절전 설정 변경을 감지합니다. 주행을 시작하지 않았거나 종료한 상태에서도 반영하고, 앱으로 복귀할 때도 다시 확인합니다.
- 배터리 보호 기능으로 실제 충전이 잠시 멈춰도 외부 전원에 연결돼 있으면 배터리 부족만으로 절전하지 않습니다. 기기 발열이나 Android 절전 조건이 남아 있어도 수동으로 일반 모드를 선택할 수 있습니다.
- 직접 켠 절전모드는 충전기 연결 후에도 유지하며, 같은 버튼으로 해제할 수 있습니다.

기존 정식 배포와 같은 서명키입니다. 1.3.3에서는 앱의 업데이트 확인으로 설치할 수 있습니다. 기존 앱을 삭제할 필요가 없습니다.

실제 폰 확인: 낮은 배터리에서 자동 절전 후 버튼 해제, 충전기 연결·분리, 화면 껐다 켜기/앱 복귀, 설치 후 설정·즐겨찾기 유지. 실제 주행 없이 정차 상태에서 확인할 수 있습니다.

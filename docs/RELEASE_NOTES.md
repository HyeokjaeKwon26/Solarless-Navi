SolarLess Navi 1.3.29

인터넷용 음성을 앱의 목소리 선택 목록과 재생 대상에서 제외했습니다.

- 기존 인터넷용 선택은 동일 엔진·음성 코드의 기기용 항목이 있으면 연결합니다. 없으면 기기용 기본 음성으로 전환합니다. 속도·음높이와 한영 혼합 모드는 유지합니다.
- 시스템 기본값이 인터넷용이어도 설치된 기기용 음성만 사용합니다. 필요한 기기용 음성이 없으면 인터넷 음성을 자동 사용하지 않고 설치를 안내합니다.
- 전경·PiP·화면 꺼짐 안내는 같은 네이티브 음성 정책을 사용합니다. 폰 전체의 TTS 음성이나 다른 앱 설정은 삭제하지 않습니다.

같은 화자에 한국어·영어 발음만 바꾸는 기능을 완성한 업데이트는 아닙니다. 현재 ‘한 목소리’는 영어 발음이 선택한 엔진에 의존하며, ‘언어별 목소리’는 음색이 달라질 수 있습니다. 공통 Android TTS API만으로 동일 화자의 두 언어 발음을 보장할 수 없습니다.

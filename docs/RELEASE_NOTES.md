SolarLess Navi 1.1.0

이번 버전부터 새 정식 서명키를 사용합니다. 이전 키로 서명된 앱이나 디버그 앱은 삭제 후 이 APK를 새로 설치해야 합니다. 삭제하면 기존 설정·즐겨찾기 등 앱 데이터가 지워질 수 있으므로 필요한 내용은 먼저 별도로 기록하세요.

- 앱 실행 시 새 버전을 확인하고 설정에서 수동으로 확인할 수 있습니다.
- APK 다운로드 진행률·취소·파일 및 서명 검증·Android 설치 화면 연결을 제공합니다.
- 주행 중에는 업데이트 알림과 설치를 미룹니다.
- GPS 오류와 통신 단절 대응, 차로 안내, 햇빛 경로 후보 탐색을 개선했습니다.
- 주행 진단 기록과 로컬 재생 도구를 추가했습니다.

이번 APK를 설치한 뒤에는 같은 새 서명키로 배포한 후속 버전을 앱의 업데이트 알림이나 설정 → 업데이트 확인으로 설치할 수 있습니다. 설치는 Android 화면에서 사용자가 확인합니다.

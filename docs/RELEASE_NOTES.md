SolarLess Navi 1.3.25

주행 지도의 가독성과 조감도 표시를 개선했습니다.

1. 도로명 대비·크기를 조정하고 POI를 줄이는 주행용 벡터 지도 스타일을 추가했습니다.
2. 실제 경로 위에 다음 회전과 가까운 연속 회전 화살표를 표시합니다.
3. 경로를 가리지 않는 주변 3D 건물을 제한적으로 표시하고 교차로·도착점·발열 시 숨깁니다.
4. 도착점/선택 입구와 경로 끝을 함께 보여주고 차이가 있으면 주행 경로가 아닌 점선으로 구분합니다.
5. Android에서 본 지도만 최대 32 MiB 페이로드로 캐시합니다. 저장 지도 사용 표시와 삭제/해제를 제공합니다. 전국 오프라인 지도는 포함하지 않습니다.
6. 기존 분석에 따른 예상 그늘·노출·자료 부족을 경로 주변 띠로 볼 수 있습니다.
7. 선택적으로 무료 입체 지형과 약한 지형 음영을 켤 수 있습니다. 자료 오류 시 평면 지도를 유지합니다.

설정 → 지도 표시와 저장 공간에서 조절할 수 있습니다. 그늘 띠와 입체 지형은 기본으로 꺼져 있습니다. 추가 표현은 발열·렌더 지연 시 줄이며 GPS·회전·음성 안내 주기는 유지합니다.

유료 API·지역 지도 DB를 추가하지 않았고 기존 정식 서명을 유지합니다. 실제 배터리 사용량과 주행 가독성은 폰에서 별도 확인이 필요합니다.

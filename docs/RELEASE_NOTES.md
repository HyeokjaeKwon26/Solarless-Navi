SolarLess Navi 1.3.32

음성 안내 신뢰성, 운전하기 편한 경로 선택, 설정 화면을 개선했습니다.

- 지난 회전 안내는 다음 회전으로 바뀌면 취소합니다. 늦게 도착한 재생 요청과 오래 대기한 음성도 차단합니다.
- 전체 설정 → 안내 목소리에서 이번 실행의 엔진 재생 요청·시작·완료·오류·시간 초과와 시작 지연을 확인할 수 있습니다. 실제 스피커 소리를 자동 판정하는 기능은 아닙니다.
- 기본/선택 음성 비교 후 청취 결과를 목소리·속도·음높이 조합별로 기기에 저장할 수 있습니다.
- 기존 단순 경로를 ‘운전하기 편한 경로’로 개선했습니다. 유턴·회전·짧은 간격의 연속 회전·급회전을 비교하고, 추가 시간은 설정 한도와 최대 2분·20% 이내로 제한합니다. 원래 최단시간 값은 유지합니다.
- 기본 설정에는 경로·화면·목소리·업데이트를 모았습니다. 진단·시뮬레이션 등은 전체 설정에서 열 수 있습니다. 기존 설정값은 유지합니다.

새 TTS 엔진·음성 모델·지도 묶음을 추가하지 않았으며 GPS 수신 주기와 회전 안내 거리를 낮추지 않았습니다. 도로 폭 자료가 없는 후보를 좁은 길이라고 추정하지 않습니다.
실제 폰의 한영 발음, 블루투스·PiP·화면 꺼짐, 연속 회전 안내와 운전 난이도는 별도 현장 확인이 필요합니다.

SolarLess Navi 1.3.16

경로 선호도, 전체 여정 미리보기, 확인된 전면 통제에 대한 우회 제안을 추가했습니다.

- 설정 → 경로 선택에서 최단시간 / 회전·유턴 적게 / 역광 회피 / 그늘 우선과 최대 추가 주행 시간(0·2·5·10분)을 선택합니다. 수신된 후보 안에서 선택하며, 햇빛 경로가 한도를 넘으면 최단시간 경로를 사용합니다.
- 전체 여정 미리보기에서 현재 목적지와 이후 최대 3개 목적지의 경로·구간별 시간·총 주행 시간을 확인합니다. 정차 시간은 제외되며, 이후 구간은 기본 도로 속도 추정입니다. 해당 구간 시작 때 선호도로 다시 계산합니다.
- 주행 전에 경유 순서를 바꿀 수 있습니다. 도착 후 다음 구간으로 이어가거나 현재 구간을 건너뛸 수 있으며, 정차와 정확한 GPS를 확인한 뒤 다음 경로를 미리 보여줍니다. 안내 시작은 사용자가 선택합니다.
- 기존 공개 피드가 남은 경로의 전면 통제를 확인하면 우회 후보와 시간 차이를 제안합니다. 사용자가 승인해야 바뀝니다. 위치·방향·경로·통제 자료가 달라지거나 오래된 제안은 적용하지 않습니다.
- 이미 지나간 첫 도로 단계의 geometry를 남은 구간에서 제거해 뒤쪽 통제를 앞으로 오인하는 경우를 방지합니다.

무료 공개 데이터의 범위와 누락 한계는 유지됩니다. 전국 실시간 정체 정보, 차량 입구 보장, 완전한 다중 경유 최적화는 제공하지 않습니다. 지도 DB를 APK에 추가하지 않았습니다. 기존 패키지와 서명키를 유지합니다.

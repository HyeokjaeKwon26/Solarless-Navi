SolarLess Navi 1.3.22

주행 화면과 위치·진단 기록의 반복 작업을 줄였습니다.

1. 조감도 경로를 64개 선분 단위로 나눠 차량 주변만 갱신합니다. 먼 경로는 분석 결과가 바뀔 때 갱신하며, 화면 크기 측정·버튼 변경·보이지 않는 2D 차량 마커의 반복 갱신을 줄였습니다.
2. 정확도와 안내 시점을 우선해 Android 주 GPS의 250ms 요청을 유지합니다. 신선하고 정확한 네이티브 GPS가 연속 확인된 동안에만 중복 WebView 구독을 쉬게 하며, 수신 중단·정확도 저하·서비스 오류 시 복구합니다. 위치를 충분히 자주 받지 못하는 기기에서는 기존 구독을 유지합니다.
3. 최신 위치는 메모리에서 즉시 전달하고 복구용 디스크 사본은 2초 간격으로 저장합니다. 진단 위치 기록은 최대 1초 단위로 묶고, 주요 이벤트·내보내기·종료·백그라운드 전환 때 저장합니다.

기존 정식 서명키를 유지합니다. 배터리 절감률과 실제 주행 지연은 기기별 비교 측정 전이며 수치로 보장하지 않습니다. 비정상 종료 직전의 미저장 위치·진단 기록은 각각 약 2초·1초 범위에서 유실될 수 있습니다.

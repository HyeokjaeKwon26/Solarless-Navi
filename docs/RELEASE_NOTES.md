SolarLess Navi 1.3.6

출발지·목적지 검색 버튼의 돋보기 아이콘이 왼쪽으로 치우쳐 보이던 문제를 수정했습니다. 버튼 안에서 아이콘을 가로·세로 중앙에 배치합니다.

1.3.5에서는 앱의 업데이트 확인 → 다운로드 → 설치로 업데이트할 수 있습니다. Android의 설치 허용 및 최종 설치 확인은 직접 진행해야 합니다. 1.3.4 이하에서는 APK를 직접 내려받아 덮어 설치해 주세요. 1.1.0 이후 정식 배포와 동일한 서명키를 유지합니다.

실제 폰 확인: 두 검색 버튼의 아이콘 중앙 정렬, 1.3.5에서 앱 내 다운로드와 설치 화면 전환, 설치 후 설정·즐겨찾기 유지. 이 수정은 실제 주행 확인이 필요하지 않습니다.

SolarLess Navi 1.3.14

한국어와 영어 안내 목소리를 따로 선택하고 속도·음높이를 조절할 수 있습니다.

- 설정 → 안내 목소리에서 한국어와 영어 음성을 각각 선택합니다. 한국어 안내 중 영어 도로명도 선택한 영어 목소리로 읽습니다. 실제 음성 엔진이 제공한 이름을 표시하며, 인터넷이 필요한 목소리를 구분합니다.
- 한국어·영어 각각 미리 듣기와 기존 혼합 도로명 미리 듣기를 지원합니다. 음소거 상태이거나 주행 안내 중에는 미리 듣기로 안내를 방해하지 않습니다.
- 말하기 속도는 0.50–1.50배, 음높이는 0.75–1.50배로 조절합니다. 두 언어에 공통 적용하며 1.00배가 기본입니다. 설정은 자동 저장되고 초기화 버튼으로 되돌릴 수 있습니다.
- Android의 화면 안 안내, PiP·화면 꺼짐 중 안내가 같은 저장 설정을 읽습니다. 변경은 다음 안내부터 적용되며 앱 재실행 후에도 유지합니다.
- 목록 순서 대신 음성 엔진과 음성 이름을 함께 저장합니다. 삭제되거나 사용할 수 없어진 선택 음성은 같은 언어의 기본 음성으로 대체하고 설정 화면에 표시합니다. 해당 언어 자체가 설치되지 않은 경우에는 기존 언어 대체/재생 불가 처리를 유지합니다.
- 목소리가 추가되지 않았다면 목록 새로고침을 이용하세요. Android의 기본 음성 엔진 자체를 변경했다면 앱을 다시 시작해야 합니다. 앱에 대형 음성 모델을 포함하지 않습니다.

기존 정식 배포와 같은 서명키를 사용합니다. 앱에서 업데이트 확인 → 다운로드 → Android 설치 확인으로 업데이트할 수 있습니다.

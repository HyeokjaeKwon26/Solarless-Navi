SolarLess Navi 1.3.3

업데이트 확인 시 `Invalid update information.`이 표시되는 오류를 수정했습니다.

- 지도 데이터 배포까지 포함한 전체 GitHub 목록(약 5.9MB)이 앱의 응답 크기 제한에 걸리던 문제입니다. 이제 앱 태그와 해당 앱의 배포 정보만 조회합니다.
- 게시 준비 중인 태그와 사전 배포 버전은 건너뛰고, 공개된 정식 앱 버전을 확인합니다.
- 시작 시 새 버전 안내와 계속 사용, 설정에서 수동 확인, 다운로드·서명 검증·설치 흐름은 유지합니다.

1.3.2 이하에서 업데이트 확인이 막히면 이 릴리스의 APK를 직접 받아 덮어 설치하세요. 1.1.0 이후 정식 배포와 같은 서명키를 사용하므로 기존 앱을 삭제할 필요가 없습니다.

실제 폰 확인: 덮어 설치 후 데이터 유지, 수동 확인 시 최신 버전 표시, 다음 배포 시 시작 안내 및 다운로드·Android 설치 완료. 실기기 설치와 주행 검증은 별도입니다.

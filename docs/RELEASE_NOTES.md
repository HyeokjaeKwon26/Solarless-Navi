SolarLess Navi 1.3.1

정식 1.1.0~1.3.0과 같은 서명키를 사용합니다. 기존 앱을 삭제하지 않고 설정 → 업데이트 확인에서 설치할 수 있습니다.

- 주소 입력 시 번지·도로명이 다른 자동완성 후보를 제외합니다. `rd`, `ave` 등 도로 약어를 인식하고 주소 제목에 번지를 표시합니다.
- 입력칸 옆 돋보기, Enter 또는 ‘목적지 검색’을 누르면 주소 후보를 표시합니다. 첫 결과로 바로 경로를 시작하지 않으며, 도시·주·우편번호와 출발지로부터의 거리를 확인한 뒤 직접 선택합니다. GPS 출발지가 없으면 거리는 표시하지 않습니다.
- 검색 결과가 없을 때 도시·주·우편번호를 추가하도록 안내합니다. 입력을 수정하면 이전 후보와 대기 중 검색을 취소합니다.
- 첫 화면의 ‘지도 / Map’ 버튼을 제거했습니다. 기존 우측 상단 설정 버튼으로 검색 화면에서 바로 설정을 열 수 있습니다.
- 긴 Free drive 설명이 스위치를 밀어내지 않도록 텍스트 줄바꿈과 스위치 고정 폭을 적용했습니다.

주소 데이터에 없는 곳의 정확한 위치를 보장하지는 않습니다. 같은 번지·도로명이 여러 도시에 있으므로 목록의 전체 주소를 확인해 선택해 주세요. 자동완성은 Photon, 명시적인 주소 검색은 기존 Nominatim 연동을 사용합니다.

실제 폰 확인: 1.3.0에서 앱 삭제 없이 업데이트, 키보드가 열린 상태의 주소 선택, 시스템 글자 크기를 키운 상태의 설정 스위치 배치. 이번 수정은 검색·설정 화면에 한정되며 실제 주행 검증을 수행한 것은 아닙니다.

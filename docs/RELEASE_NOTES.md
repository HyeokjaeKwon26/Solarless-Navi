SolarLess Navi 1.3.12

무료 공개 데이터에 기반한 통제 구간 판단, 차량 도착점 확인, 교차로 안내를 개선했습니다.

- MassDOT의 현재 전면 통제 중 시작·종료 시각과 위치가 확인되고 도로명·진행방향·주행 구간이 일치하는 경로를 후보에서 제외합니다. 초기 미리보기에도 적용합니다. 모든 후보가 통제를 지나면 경로를 확정하지 않고 이유를 표시합니다.
- 단순 공사·일부 차로 통제·오래된 자료·확인되지 않은 통제는 전면 폐쇄로 간주하지 않습니다. 실시간 속도 미반영과 공개 자료 수신 실패를 표시합니다.
- 목적지에서 차량 진입점/주차장 입구를 직접 확인하고 즐겨찾기에 저장할 수 있습니다. 확인한 핀을 다시 불러와도 유지하며, 핀을 옮기면 확인 표시를 해제합니다.
- ‘도착 구간 미리보기’에서 마지막 주행 구간, 실제 경로 끝, 목적지 핀과 두 지점의 거리 차이를 확인할 수 있습니다.
- 지도 데이터의 차로 방향 화살표와 추천 차로를 표시합니다. 현재 차량의 차로를 감지하는 기능은 아닙니다. 연속 회전에는 다음 도로를 표시·발음하며, 복잡한 분기점은 미리 안내하고 직전 안내는 간결하게 합니다. Android 백그라운드 안내에도 적용합니다.

공개 공사 정보는 모든 도로를 포괄하지 않습니다. 검사 당시 MassDOT의 활성 전면 통제 25건은 필요한 검증 필드가 충족되지 않아 경고로만 처리되었습니다. NYC 일부 센서 외에 광역 정체 속도를 새로 제공하지 않으며, 충분한 주행 기록이 없어 학습 ETA 보정은 추가하지 않았습니다. 사용자 확인 진입점은 공식 출입 허가의 검증이 아닙니다.

기존 정식 배포와 같은 서명키를 사용합니다. 앱에서 업데이트 확인 → 다운로드 → Android 설치 확인으로 업데이트할 수 있습니다.

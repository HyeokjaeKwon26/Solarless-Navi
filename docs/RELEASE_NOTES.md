SolarLess Navi 1.3.0

정식 1.1.0/1.2.0과 같은 서명키를 사용합니다. 앱에서 업데이트 확인 → APK 다운로드 → Android 설치 확인으로 업데이트할 수 있으며, 기존 정식 앱을 삭제할 필요가 없습니다.

1. 주행 진단을 기기에 지속 저장합니다. Android는 최대 8 MiB 순환 파일을 사용합니다. 기록 시작·중지·내보내기·삭제, 경로/GPS/음성 이벤트 재생을 지원하며 외부 업로드는 없습니다.
2. Android 네이티브 음성과 오디오 포커스를 연결했습니다. 화면이 꺼져도 서비스가 유지되고 GPS가 유효하면 저장된 경로의 회전 안내를 계속합니다. 불확실한 위치에서는 회전 지시를 멈춥니다. 백그라운드 새 경로 계산은 포함하지 않습니다.
3. 교차로 접근 시 속도에 맞춰 지도를 확대하고 제공된 차로 번호·연속 회전을 강조합니다. 자동 확대는 끌 수 있으며 지도 수동 조작 중에는 대기합니다.
4. 남은 경로의 일광·예보·ETA를 5분 간격으로 재평가합니다. GPS가 불확실하거나 회전이 임박하면 미룹니다. 갱신 시각과 추정 가정을 표시하며 선택 경로를 임의로 바꾸지 않습니다.
5. 키 없이 NYC DOT 센서 이동시간과 MassDOT 공사·통제 공개 피드를 연결했습니다. 신선하고 방향·형상이 맞는 센서 관측만 ETA/후보 비교에 반영합니다. 지원 지역 밖·지연·누락 데이터는 기본 ETA로 표시합니다. 공사 정보는 주변 주의 정보이며 자동 통제 회피나 전국 정체 정보가 아닙니다.
6. 지도 주변 약 3 km 폭의 OSM 도로를 미리 저장하면 저장 도로 안에서 오프라인 재탐색이 가능합니다. 7일간 유효하며 일방통행·진입·회전 제한을 적용합니다. 연결이 없거나 위치가 모호하면 경로 생성을 거부합니다. 지도 타일은 포함하지 않습니다. 공개 서버 제한·장애 시 다운로드가 실패할 수 있습니다.

첫 검색 화면에 ‘지도 / Map’ 버튼을 추가해 주행 시작 없이 도로 저장·진단 설정에 접근할 수 있습니다.

자동 검증 범위와 실제 폰·주행 확인 항목은 [1.3.0 검증 문서](https://github.com/HyeokjaeKwon26/Solarless-Navi/blob/main/docs/DRIVING_VALIDATION_1.3.0.md)에 정리했습니다. 실제 차량에서의 음성·블루투스·배터리·도로 판단 성능은 별도 확인이 필요합니다.

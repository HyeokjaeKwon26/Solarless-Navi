SolarLess Navi 1.3.8

속도계만 mph로 바뀌고 경로·회전 거리는 km/m로 남던 단위 혼용을 수정했습니다. 속도, 제한속도, 경로·남은 거리, 회전 안내, 검색 거리, 도착 결과와 음성 안내가 같은 단위 설정을 사용합니다. Android 백그라운드 음성에도 해당 설정을 전달합니다.

설정의 ‘거리·속도 단위 / Distance and speed units’에서 자동, km/m·km/h, mi/ft·mph를 선택할 수 있습니다. 자동 모드는 현재 위치 기준으로 미국·영국에서 mi/ft·mph를 사용하며, 한국 등에서는 km/m·km/h를 사용합니다. 수동 선택은 앱을 다시 켜도 유지되며 언어 선택과 독립적입니다.

시작 시 국가 조회가 늦게 완료되어 속도 숫자와 단위가 따로 바뀌던 문제를 수정했습니다. 같은 원래 속도값을 이용해 숫자와 단위를 함께 갱신합니다. 내부 경로 계산과 과속 판정 단위는 유지합니다.

영어 경로 카드의 시간 ‘5m’을 ‘5 min’으로 바꾸어 거리의 m과 구분했습니다.

GPS 보정 대기 중에는 주기적인 상태 확인이나 단위·언어 변경이 ‘GPS 보정 중’ 안내를 덮어쓰지 않도록 했습니다.

1.3.5 이상에서는 앱의 업데이트 확인 → 다운로드 → 설치로 업데이트할 수 있습니다. Android의 설치 허용 및 최종 설치 확인은 직접 진행해야 합니다. 1.3.4 이하에서는 APK를 직접 내려받아 덮어 설치해 주세요. 1.1.0 이후 정식 배포와 동일한 서명키를 유지합니다.

실제 폰 확인: 앱 내 업데이트 설치, 단위 설정 유지, 한국어·영어 음성, 화면을 끈 상태의 Android 안내 및 PiP. 실제 주행 확인: GPS 속도·제한속도·회전 거리의 단위 일치와 단위 변경 후 안내 연속성. 운전 중 조작은 동승자가 진행해 주세요.

SolarLess Navi 1.3.26

무료 기능 범위에서 주행 품질 검증, 햇빛 회피 탐색, 지도 가독성, 경로 비교, 저장공간 관리를 개선했습니다.

1. 정답 라벨이 있는 주행 기록의 위치 오류·안내 조건 지연·불필요 재탐색 제안을 배포 전 자동 검사합니다. 라벨이 없는 항목은 미확인으로 표시합니다. 현재 배포 기준 기록은 합성 자료이며 실제 주행 성능을 입증하지 않습니다.
2. 저장된 지역 도로가 있으면 합법적으로 연결되고 다시 합류하는 도로 분기를 우회 후보로 우선 탐색합니다. 기존 서버 요청 상한을 유지하며, 자료가 없으면 기존 탐색을 사용합니다.
3. 조감도에서 현재 도로와 다음 진입 도로 이름을 우선 표시하고 GPS가 불확실하면 숨깁니다.
4. 주행 전 대안 경로의 갈라지는 구간·공유 구간·예상 눈부심을 지도에서 비교합니다. 같은 경로는 묶고, 경로 선택은 그대로 유지합니다.
5. 지도·정밀 자료·저장 도로·주행 기록의 사용량을 함께 확인하고 160/240/400 MiB 관리 예산을 선택할 수 있습니다. 안내·경로 계산 중에는 삭제를 막습니다. APK·WebView 캐시·DB 부가 용량은 별도입니다.
6. 기본/상세/저부하 지도 프리셋을 추가했습니다. 개별 설정은 유지하며, 기본 설정에서 추가 지형과 그늘은 꺼져 있습니다.

GPS·회전 판단·음성 안내 주기를 낮추지 않았습니다. 유료 API나 전국 오프라인 지도 DB를 추가하지 않았으며 기존 정식 서명을 유지합니다.

실제 폰의 배터리 소모, 화면 꺼짐/PiP 안내, 실제 우회 효과는 별도 확인이 필요합니다.

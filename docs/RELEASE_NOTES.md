SolarLess Navi 1.3.10

GPS 위치 판단과 신호 복구를 개선했습니다. 평행도로·반복 교차로에서 위치 오차가 크면 회전 안내를 보류합니다. GPS가 15초 넘게 끊겼거나 도로 판단이 모호했던 경우 연속된 두 위치가 일치해야 안내를 재개합니다. 중복·역순 위치는 복구 확인으로 세지 않습니다. 모호한 위치만으로 재탐색하지 않으며, 단위 변경으로 보류한 안내가 다시 나타나던 문제도 수정했습니다. Android 백그라운드 안내에도 복구 확인을 적용했습니다.

주행 집중 화면에서는 도착 예정·남은 시간·남은 거리를 동시에 표시합니다. 긴 경로 설명은 ‘경로 분석 보기’에서 확인하며, 설정에서 집중 화면을 끌 수 있습니다. 앱 복귀 시 지도 크기를 다시 확인합니다. 안내 도중 앱을 다시 열면 최근 경로의 선을 점선으로 미리 볼 수 있습니다. 저장 경로는 최대 12시간 유효하며, 새 경로 확인 전에는 안내를 시작할 수 없습니다. 지도 타일을 저장하는 기능은 아닙니다.

‘주행 품질 요약’에서 선택적으로 기록한 위치, 도로 매칭 상태, GPS 간격, 재탐색 시간·실패, 완료 주행의 ETA 오차를 확인합니다. Android 위치 기록은 화면 위치 기록과 따로 집계합니다. 기록을 중간에 켰거나 껐거나 목적지를 바꾼 주행은 전체 ETA 평가에서 제외합니다. 진단 JSON 내보내기와 로컬 재생 도구에도 요약이 포함됩니다. 기록은 기기에 저장되며 자동 업로드하지 않습니다.

경로 분석에는 기준 경로보다 더 걸리는 시간과 직사광선 노출 예상 감소 시간을 표시합니다. 분석 방식·날씨 조건이 다르면 감소량을 직접 비교하지 않습니다. 햇빛 회피는 계산상 예측이며 실제 효과를 측정했다는 뜻이 아닙니다. 광역 실시간 교통 데이터나 새로운 상용 경로 엔진을 추가한 버전은 아닙니다.

기존 정식 배포와 동일한 서명키를 유지합니다. 1.3.5 이상은 앱에서 업데이트 확인 → 다운로드 → Android 설치 확인으로 업데이트할 수 있습니다. 이전 버전은 APK를 직접 내려받아 덮어 설치해 주세요.

실제 폰 확인: 업데이트 후 설정 유지, 작은 화면·큰 글꼴·가로 화면, 화면 끄기·PiP·앱 복귀, 통신 단절 후 저장 경로 표시와 재연결, 진단 저장·삭제.
실제 주행 확인: 평행도로·교차로 및 터널 출구에서 매칭과 안내 복구, 실제 이탈 재탐색 시간, 도착 ETA 오차, 햇빛 예측과 실제 노출 비교. 운전 중 조작과 기록은 동승자가 진행해 주세요.

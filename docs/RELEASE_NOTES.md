SolarLess Navi 1.3.5

업데이트 다운로드 오류, 주소 검색 흐름, 동일 경로 안내를 수정했습니다.

- 업데이트 다운로드에서 APK 크기와 버전 번호를 0으로 잘못 읽어 `Invalid update information`이 표시되던 Android 코드 오류를 수정했습니다. 파일 크기·해시·앱 서명·버전 검증은 유지합니다.
- 주소 추천 목록에 `입력한 주소 검색` 버튼을 추가했습니다. 추천 결과가 비어 있어도 이 버튼으로 전체 주소 검색을 실행하고, 도시가 표시된 결과를 직접 선택할 수 있습니다.
- 검색 서비스 일부가 응답하지 않으면 `주소 없음` 대신 연결 오류와 재검색 버튼을 표시합니다. 일시적인 빈 결과를 앱 실행 내내 보관하지 않아 다시 검색할 수 있습니다.
- 역광·그늘 경로가 최단시간 경로와 같을 때는 탐색한 후보 중 감소 효과와 우회시간 기준을 충족한 대안이 없다는 뜻으로 안내합니다. 다른 주행 경로가 전혀 없다는 의미가 아닙니다.

설치 안내: 1.3.4 이하의 앱에는 다운로드 오류가 남아 있으므로 이번 1.3.5 APK는 GitHub 배포 페이지에서 직접 내려받아 설치해 주세요. 기존 정식 배포와 같은 서명키이며, 기존 앱을 삭제하지 않고 덮어 설치합니다. 설치 후에는 수정된 앱 내 다운로드 기능을 사용합니다. Android의 설치 허용 및 최종 설치 확인은 직접 진행해야 합니다.

실제 폰 확인: 덮어 설치 후 설정·즐겨찾기 유지, 주소 검색 및 후보 선택, 다음 새 버전 배포 시 앱 내 다운로드와 설치 화면 연결. 주소·업데이트 확인은 정차 상태에서 가능합니다. 실제 도로의 진입 가능 여부·회전 안내·위치 추종은 별도 주행 확인이 필요합니다.

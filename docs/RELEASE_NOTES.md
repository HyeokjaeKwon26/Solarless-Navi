SolarLess Navi 1.3.7

경로 카드와 예상시간은 나오지만 지도에 경로선·전체 미리보기가 나타나지 않던 문제를 수정했습니다. 오래된 GPS, 정확도가 낮은 GPS, 직접 선택한 출발지에서도 계산된 경로를 미리 볼 수 있습니다. 실제 안내 시작 시에는 현재 GPS를 재확인하고 필요한 경우 경로를 다시 계산합니다.

지도 오른쪽 아래에 ‘범례 / Colors’ 버튼을 추가했습니다. 주황은 예상 눈부심 위험, 보라는 건물·지형 분석으로 계산한 그늘, 청록은 간이 추정 그늘, 파랑은 기본 구간, 회색 점선은 선택하지 않은 후보 경로입니다. 교통 정체 표시가 아니며 현장에서 확인한 결과를 뜻하지 않습니다.

1.3.5 이상에서는 앱의 업데이트 확인 → 다운로드 → 설치로 업데이트할 수 있습니다. Android의 설치 허용 및 최종 설치 확인은 직접 진행해야 합니다. 1.3.4 이하에서는 APK를 직접 내려받아 덮어 설치해 주세요. 1.1.0 이후 정식 배포와 동일한 서명키를 유지합니다.

실제 폰 확인: 주소 선택 후 전체 경로 미리보기, 범례의 한·영 전환과 Android 뒤로가기, 앱 내 업데이트 설치와 설정·즐겨찾기 유지. 실제 GPS·주행 확인: 정확도가 낮은 위치에서 안내를 시작한 뒤 GPS가 안정되면 현재 위치 기준 경로로 전환되는지 확인해야 합니다.

SolarLess Navi 1.3.31

기존 TTS 엔진을 사용하는 한영 혼합 안내 경로를 수정하고, 기본·선택 목소리 비교 미리 듣기를 추가했습니다.

- 한 목소리 모드에서 영어 도로명의 언어 정보를 유지해 한 문장으로 전달합니다. 앱이 영어 도로명마다 다른 목소리를 선택하지 않습니다.
- 기본 목소리의 불필요한 재지정을 제거하고, 선택한 음성을 지정한 뒤 언어 설정으로 다시 덮어쓰지 않습니다.
- 업그레이드 시 한 번 ‘한 목소리’로 전환합니다. 선택한 한국어·영어 음성, 속도, 음높이는 보존하며 이후 명시적으로 고른 언어별 모드는 유지합니다.
- 설정의 한국어 미리 듣기 아래에서 기본/선택 음성으로 같은 문장을 비교할 수 있습니다. 비교는 설정을 바꾸지 않고 주행 중에는 차단합니다.
- Harvard Av.도 Harvard Avenue로 확장합니다. 인터넷용 음성과 새 엔진·모델은 추가하지 않습니다.

실제 엔진이 언어 정보를 반영하는지, 동일 화자로 자연스러운 영어를 발음하는지는 폰 청취가 필요합니다. 이번 검증은 코드·모의 엔진·자동 테스트이며 실제 폰의 발음 개선 완료를 의미하지 않습니다.

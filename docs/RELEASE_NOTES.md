SolarLess Navi 1.3.36

화면 꺼짐 복구의 경로 선호, 여행별 저장, 갈림길과 주소 결과, 도착 후 주차 위치를 개선했습니다.

- 주행 재생에서 라벨로 확인한 위치 오류·안내 조건 지연·불필요 재탐색 시점으로 바로 이동할 수 있습니다. 실제 주행 기록이 아직 없어 현장 정확도 개선은 미검증입니다.
- 백그라운드 복구 시 최대 3개 후보에서 회전이 적은 경로를 비교합니다. 햇빛 선호는 시간·방향·구간이 맞는 저장 분석이 후보 전체에 있을 때만 반영합니다. 자료가 부족하면 일반 경로 복구 이유를 표시합니다.
- 선택 경로·회전 정보를 24시간 보관할 수 있습니다. 같은 출발점·목적지·방향·통행료 조건에서만 통신 실패 시 재사용합니다. 주변 도로는 12km 이하 경로에 한해 선택 저장하며, 여행·도로 합계 12MiB 한도를 유지합니다. 배경 지도·완전한 오프라인 내비게이션을 보장하지 않습니다.
- 교차로 개요에 저장 지도에서 확인된 연결 도로를 추가합니다. 연결되지 않은 고가·지하 도로를 임의로 이어 그리지 않습니다.
- 검색 결과에 번지·도로명·입력 지역의 일치 근거를 표시합니다. 기존 엄격한 번지 필터와 입구 확인은 유지합니다.
- 도착 후 정차를 확인하고 현재 주차 위치를 저장할 수 있습니다. 목적지까지 직선거리·방위를 표시하며 보행 경로로 표현하지 않습니다. 기기에 한 건만 30일 보관하며 삭제할 수 있습니다.

무료 공개 서비스와 기존 엔진을 사용합니다. GPS·음성 안내 주기를 낮추지 않았으며 대형 지도나 음성 모델을 추가하지 않았습니다. 실제 폰·주행·배터리 결과는 별도 확인이 필요합니다.

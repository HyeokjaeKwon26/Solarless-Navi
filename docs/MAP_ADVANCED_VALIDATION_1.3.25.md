# SolarLess Navi 1.3.25 — 주행 지도 개선

버전 1.3.25 / versionCode 29. 기존 패키지와 정식 서명을 유지한다. 유료 API·계정·서버와 지역 지도 DB를 추가하지 않는다.

## 요청한 1–7번

1. **주행용 지도 스타일:** 벡터 지도의 도로명 대비·크기·테두리를 조정하고 POI 문구를 줄였다. 일반 도로와 건물의 표현을 정리하되 교량·터널·철도·도로 폭과 기존 경로 색상은 유지한다. 설정을 끄면 원래 스타일로 돌아간다. 래스터 대체 지도는 제공자의 원래 그림을 사용한다.
2. **지도 위 회전 화살표:** 500m 이내 다음 회전과 180m 이내 연속 회전을 실제 경로 모양 위에 표시한다. 회전 전후 35m 구간과 화살촉을 사용하며 없는 연결·차로를 만들지 않는다. GPS가 불확실하면 숨긴다. 기존 교차로 개요·안내 판단과 함께 사용한다.
3. **주변 3D 건물:** 조감도에서 주변 약 450m, 표시 높이 최대 60m, 확대 수준 15 이상만 표시한다. 경로와 100m 이내인 건물은 부분 겹침도 제외하고 차량 주변도 비운다. 180m 이내 회전·도착점·GPS 불확실·발열/렌더 지연에서는 숨긴다. 높이 제한과 투명도는 가독성을 위한 표현이며 실측 높이를 보장하지 않는다.
4. **도착점 지도:** 신뢰할 수 있는 경로 진행으로 남은 350m, 차량과 경로 끝의 거리가 500m 이내일 때 경로 끝과 선택한 도착점/입구를 같이 표시하고 화면 안에 넣는다. 10m 이상 차이는 점선으로 구분하며 주행 가능한 연결 도로로 표시하지 않는다. 입구 확인 여부는 기존 사용자의 선택을 유지한다.
5. **본 지도 캐시:** Android에서 실제 요청한 OpenFreeMap·Mapterhorn 자료만 저장한다. 최대 32 MiB 페이로드·1,500개 자원, 개별 2 MiB, 보관 7일, 네트워크 동시 요청 4개, 임시 저장 복사본 4개로 제한한다. 사전 광역 다운로드는 하지 않는다. HTTP 저장 금지 조건을 지키고 통신 실패 시 보관 기한 안의 저장 자료를 사용하며 표시한다. 캐시 삭제/사용 해제가 가능하다. IndexedDB 오버헤드·기존 WebView HTTP 캐시·기존 장면/도로 자료는 이 상한과 별도다. 완전한 오프라인 지도·경로 검색을 보장하지 않는다.
6. **예상 그늘 띠:** 기존 장면 분석 결과를 경로 주변의 넓은 띠로 표시한다. 보라색은 예상 그늘, 노란색은 노출, 회색은 자료 부족이다. 최대 64구간·약 1km만 사용하고 오래된/불확실한 차폐 결과를 확정 그늘로 바꾸지 않는다. 주변 전체의 그림자 외곽선은 아니다. 기존 햇빛 경로 색상과 분석 결과는 변경하지 않는다.
7. **입체 지형·지형 음영:** 무료 Mapterhorn DEM을 켠 화면에서 필요할 때만 읽는다. 원본 타일 최대 확대 수준 12, 고도 과장 1배, 약한 hillshade로 제한한다. 회전·도착점·발열·GPS 불확실 시 해제하고 자료 오류 시 평면 지도를 유지한다. 이 고도는 차로·고가도로·GPS의 높이 판단에 쓰지 않는다.

설정 → **지도 표시와 저장 공간 / Map display and storage**에서 각각 조절한다. 1–5번은 기본 활성화, **그늘 띠·입체 지형은 기본 비활성화**다. 2–4·6–7번의 추가 겹침 표시는 조감도 주행 화면에서 제공한다. 2D 복귀·PiP·절전·화면 꺼짐 시 기존 화면 정책을 따른다.

## 지도 자료와 성능 범위

- 배경·건물은 기존 OpenFreeMap 벡터 자료다. Mapterhorn은 별도의 화면 표시용 지형 공급자이며 출처를 지도에 표시한다.
- 업로드한 `data/scene` manifest·ZIP, 장면 로더·차폐 계산·도로 그래프는 변경하지 않았다. 기존 장면 자료와 배경/DEM의 출처·기준 시점·형상은 서로 다를 수 있다. [장면 자료 현황](SCENE_DATA_STATUS.md)의 원본 추출 시각·릴리스 참조·미반영 내역은 유지한다. 새로운 OSM 추출본 갱신이나 전국 자료 재검사는 아니다.
- GPS 수신, 경로 매칭, 회전 판단, 음성 안내 주기를 낮추지 않는다. 추가 표시는 통상 2초 간격으로 갱신하고 상태 변경에는 즉시 반영한다. 경로/차폐 계산용 타일 추가 다운로드나 별도 주행 분석 업로드는 없다.
- 벡터 렌더러의 타일 메모리 캐시는 48개로 제한한다. 실제 화면에 필요한 활성 타일·GPU 메모리까지 48개로 고정한다는 뜻은 아니다.
- CORS를 지원하는 두 공급자에 WebView fetch로 직접 요청해 실제 취소가 가능하게 한다. Android User-Agent에 앱 식별자를 붙인다.
- 배터리 절감률·현장 FPS·공급자 가용성은 실측하지 않았다. 부하 제한을 구현했지만 모든 폰에서 추가 표현의 비용이 0이라는 의미는 아니다.

공급자 문서: [OpenFreeMap](https://openfreemap.org/), [Mapterhorn](https://mapterhorn.com/), [MapLibre 지형 예제](https://maplibre.org/maplibre-gl-js/docs/examples/3d-terrain/).

## 자동 검증

단위 검사는 설정·경로 화살표·차폐 자료 신선도/누락·도착점 거리·캐시 허용 목록/HTTP 정책/LRU 상한을 검사한다. 브라우저 검사는 root/www에서 실제 MapLibre, 벡터 타일, DEM 이미지를 사용한다. 지도 내용은 재현 가능한 모의 자료이며 최신 실제 도로의 정확성을 검증하는 것은 아니다.

검사 범위: 320px 설정 배치/유지, 경로·차량 투영과 2D 복귀, 건물 필터·화살표·그늘·도착점, 지형 로딩/발열 해제/실패 복구, 캐시 재시작 후 재사용·삭제·저장 공간 오류·저장 금지·4개 동시 전송·취소. 저장과 지도 작업 스레드의 ArrayBuffer 이전 경합을 재현해 저장용 복사본을 제한적으로 분리했다.

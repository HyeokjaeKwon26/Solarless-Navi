# 1.3.16 경로 선호·여정·통제 우회 검증

버전 1.3.16 / versionCode 20. 패키지 `com.solaris.nav` 및 기존 정식 서명키를 유지합니다.

## 1. 경로 선호와 우회 한도

- 최단시간, 회전·유턴 적게, 역광 회피, 그늘 우선. 추가 시간 한도는 0·2·5·10분이며 기본 5분입니다. 기기에 저장하며 주행 중 변경은 확인 후 재탐색합니다.
- 회전·유턴 적게는 수신한 유효 후보 중 한도 내 경로를 `회전 + 8×유턴 + 2×분기` 점수, 동점이면 시간 순으로 고릅니다. 도로 폭·실제 운전 난이도 평가가 아니며 점수를 ETA에 더하지 않습니다.
- 햇빛 역할의 기존 선택 경로가 한도를 넘으면 최단시간 경로로 대체합니다. 한도 내 모든 햇빛 대안을 새로 탐색하는 알고리즘은 아닙니다. 기존 OSRM 후보 생성과 비율 제한도 유지됩니다.
- 화면과 실제 안내에 같은 설정을 적용합니다. 기존 카드의 역할 선택도 드롭다운에 반영됩니다. 방향 값이 null인 GPS를 북쪽으로 확정하지 않습니다.

## 2. 전체 여정과 구간 전환

- 현재 구간과 이후 최대 3개 구간을 하나의 지도, 구간별 시간/거리, 전체 주행 시간/거리로 표시합니다. 첫 구간은 선택한 경로의 기본 ETA, 미래 구간은 같은 통행료 조건의 OSRM 기본 경로/속도입니다. 개인 ETA·미래 정체·정차 시간을 전체 합계에 임의로 넣지 않습니다.
- 미래 구간 최대 3회, 공용 OSRM 1초 간격 대기열, 요청별 10초 제한, 60m 스냅 한도입니다. 미리보기는 사용자 요청 때만, 최소 1분 간격입니다. 실패·확인된 차단·상태 변경 시 부분 합계를 전체 ETA로 표시하지 않습니다.
- 주행 전 순서 변경은 현재 목적지를 포함합니다. 진행 중 순서 변경은 금지합니다. 건너뛰기/도착 후 이어가기는 새 GPS 속도 1m/s 이하, 정확도 35m 이하, 10초 이내 위치를 요구합니다. 속도를 모르면 전환하지 않습니다. 구간 변경 뒤 미리보기에서 사용자가 안내를 시작합니다.
- 다음 구간은 현재 GPS에서 최신 선호도로 재탐색하므로 전체 미리보기와 달라질 수 있습니다. 전 구간 동시 최적화·자동 출발 기능은 아닙니다. 목록의 기존 12시간 보존 한도를 유지합니다.
- 목적지 이름은 textContent로 표시하며 HTML로 해석하지 않습니다. 작은 화면 스크롤, 닫기, Escape/Android 뒤로 가기, 키보드 포커스 순환을 지원합니다. PiP에서는 전체 여정 창을 숨깁니다.

## 3. 확인된 전면 통제 우회 제안

- 기존 남은 경로 갱신 조건: 실제 안내, 실시간 모드, 보이는 화면, 승인된 GPS 스냅, 최근 10초 위치, 5분 간격, 남은 거리 300m 이상, 다음 안내까지 500m 초과. 화면을 끈 동안 새 네이티브 교통 조회를 수행하지 않습니다.
- 기존 도로명·진행 방향·전면 차단·시각/위치 검증·40m 이상 겹침 조건을 만족한 통제만 계기입니다. 키 없는 기존 공개 피드만 사용하며 계정/유료 API/광역 속도 데이터는 추가하지 않습니다.
- 후보 탐색은 직접 경로와 최대 4개 우회 지점, 공용 1초 간격 큐를 사용하며 전체 45초 뒤 취소합니다. 제안 계산은 최소 5분 간격입니다.
- 통제명, 우회 예상 시간, 기존 남은 경로 대비 시간 차이를 보여주고 사용자가 승인해야 변경합니다. 실패하면 유효한 우회를 확인하지 못했다고 표시합니다. 나중에 선택 시 같은 경로·같은 통제 제안을 반복하지 않습니다.
- 승인 조건: 2분 이내 제안, 동일 경로/목적지/통행료/선호/한도, 승인된 최신 스냅 GPS, 정확도 35m 이하, 제안 출발점 이동 50m 이하. 제안 당시 방향을 알았다면 현재 방향도 알아야 하며 차이는 60도 이하여야 합니다.
- 승인 순간의 현재 남은 구간에도 같은 통제가 유효해야 하고 후보는 차단되지 않아야 합니다. 오래된 피드, 지나간 통제, 이동·재탐색·설정 변경·안내 종료 뒤의 제안은 적용하지 않습니다. 정상 승인은 기존 안내 세션 갱신 경로를 통해 경로선·음성·네이티브 스냅샷으로 반영됩니다.
- 남은 첫 단계의 geometry도 남은 거리 비율로 잘라 지나간 통제를 제외합니다. 지도 단계 거리와 geometry에 기반하며 실제 도로 위치의 정답을 보장하지 않습니다.
- 무료 피드의 누락·불완전 검증으로 실제 차단을 놓칠 수 있습니다. 후보가 없다고 모든 우회로가 없다는 뜻은 아닙니다. 정체나 현장 통행 가능성을 보장하지 않습니다.

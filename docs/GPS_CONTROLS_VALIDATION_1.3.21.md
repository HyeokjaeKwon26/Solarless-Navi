# 1.3.21 GPS 상태 표시 및 지도 버튼 배치

## 변경

- 주행 화면의 상단 GPS 보정 안내와 하단 GPS 대기 문구를 제거했다. 위치가 부정확하거나 10초 동안 신뢰할 수 있는 위치가 없으면 재중앙 버튼을 노란 위성 수신 아이콘으로 표시하고 2초 주기로 천천히 점멸한다.
- 정상 GPS 수신이 돌아오면 기존 위치 아이콘과 회전 안내를 복원한다. 재중앙 버튼은 수신 불량 중에도 누를 수 있다. 기기의 동작 줄이기 설정에서는 점멸하지 않는다.
- GPS 위치 검증, 부정확한 위치에 의한 재탐색 차단은 유지한다. 오프라인·경로 서버 장애 등의 별도 상태는 계속 표시한다. 재중앙 버튼이 없는 PiP에서는 GPS 대기 상태를 유지한다.
- 세로 화면에서는 3D·범례·절전·방향·재중앙 버튼을 오른쪽 한 열로 배치한다. 높이가 낮은 가로 화면에서는 오른쪽 위 한 행으로 배치한다.
- 닫힌 설정 패널의 포커스로 지도 전체가 위로 스크롤될 수 있었던 화면 컨테이너를 보정했다.

## 실제 폰에서 확인할 항목

- 실내에서 안내를 시작했을 때 GPS 문구 두 곳 대신 재중앙 버튼만 위성 아이콘으로 점멸하는지.
- 실외에서 GPS가 회복되면 일반 위치 아이콘과 회전 안내가 자동으로 돌아오는지.
- 신호가 약할 때 재중앙 버튼을 눌러도 앱이 멈추지 않고, 신뢰할 수 없는 위치를 정상 위치로 처리하지 않는지.
- 세로·가로 전환, 글자 크기 확대, 설정 열기·닫기 후 버튼과 하단 요약이 겹치지 않는지.
- PiP 진입·복귀 및 절전 상태에서 기존 위치 안내가 유지되는지.
- 1.3.20에서 앱 업데이트를 설치했을 때 설정과 저장한 자료가 유지되는지.

실제 Android 기기와 주행 검증은 자동 브라우저 테스트로 대체하지 않았다. 신호가 약한 곳의 주행 확인은 동승자가 조작한다.

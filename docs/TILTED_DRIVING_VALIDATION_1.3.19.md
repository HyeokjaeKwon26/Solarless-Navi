# 조감도 주행·교차로 화면 검증

버전 1.3.19 / versionCode 23. 기존 com.solaris.nav 패키지와 정식 서명키를 유지한다.

## 구현

- 검색·도착점 확인·전체 경로 미리보기는 기존 Leaflet 2D 화면을 유지한다. 실제 안내와 자유 주행에는 독립 MapLibre 지도를 사용한다. 도로, 남은 경로, 차량, 도착점, 교차로 표시는 같은 MapLibre 좌표 변환을 사용한다. CSS로 평면 지도를 눕히는 방식이 아니다.
- 기본 조감도는 pitch 50°, 교차로 접근 시 32°다. 속도에 따라 접근 구간을 150~500m로 정하고 확대 수준을 조절한다. 차량을 지도 중앙보다 아래에 배치해 앞쪽 도로 공간을 확보한다. 다음 회전과 180m 이내 연속 회전 지점이 화면 안내에 가리지 않도록 실제 투영 좌표를 검사하며 확대를 제한한다.
- 주행 지도 2D/3D 버튼으로 전환하고 선택을 저장한다. 주행 종료·전체 미리보기는 2D다. 북쪽/주행 방향, 지도 끌기·확대·회전, 기존 재중앙 정렬과 탐색 후 자동 복귀를 연결했다. 수동 탐색 중에는 자동 카메라 추적을 보류한다.
- 2D로 돌아가거나 절전·PiP·화면 숨김·위성 지도를 사용할 때 조감도 렌더러를 해제한다. 조건이 해제되면 저장된 조감도 선호에 따라 복귀한다. 스타일 로드 실패·반복 지도 오류·WebGL 컨텍스트 손실은 2D로 복귀하며 자동 재시도 반복을 막는다. 사용자가 조감도 버튼으로 다시 시도할 수 있다.
- 조감도 준비가 완료된 뒤에만 기존 지도를 숨기고 기존 배경 지도 렌더러를 제거한다. 전환 중에도 2D 경로와 지도가 남는다. 야간 지도 전환에는 새 스타일을 로드하며 기존 2D 화면을 전환 중 대체 화면으로 사용한다.
- 기존 구간 분석의 색·노랑 점선을 그대로 사용한다. 인접한 같은 스타일의 구간을 한 선으로 묶고 자료 갱신 빈도를 제한한다. GPS 거부·위치 불확실·오래된 위치·다른 목적지 계산 중에는 기존 교차로를 현재 안내로 강조하지 않는다. 새 GPS 위치나 경로를 만들어 내지 않는다.
- 교차로 접근 시 다음 도로·출구를 크게 표시하고 연속 회전에는 별도 화살표를 추가한다. 공급자가 준 차로 안내만 표시한다. 가로 거치 화면은 설정 패널을 접고 안내 왼쪽·요약 오른쪽 아래·제어 버튼 오른쪽 위로 배치한다.
- MapLibre 6에서 제거된 supported()만 확인해 항상 래스터 지도로 떨어지던 초기화 조건을 수정했다. WebGL2를 확인하고 임시 확인용 컨텍스트를 해제하며, 미지원·실패 시 기존 래스터 대체 기능을 유지한다. 기존 2D 화면에서도 실제 벡터 배경을 사용할 수 있게 되어 두 렌더러를 회귀 검사한다.
- Leaflet 벡터 연결 레이어의 지연된 resize 프레임을 제거 시 취소하고, 제거·재생성 이전의 moveend 콜백은 무시한다. 빠른 절전·PiP·조감도 전환 중 이미 제거한 지도에서 getZoom을 읽던 오류를 막는다.

## 범위와 제한

- 기존 무료 OpenFreeMap/OSM 자료를 사용하며 유료 API·계정·키를 추가하지 않았다. 새 지도 DB나 3D 건물 모델을 APK에 넣지 않는다. 지도 타일 통신량과 GPU 사용량은 평면 래스터 화면과 다를 수 있다.
- 건물 입체 레이어는 주행 경로를 가리지 않도록 숨긴다. 실제 도로의 높이·고가/지하 위치나 현재 차로를 판단하는 기능이 아니다.
- 교차로 강조점은 경로 제공자가 반환한 회전 좌표다. 주변 교차로 형태·차선 수를 새로 만들어 그리지 않는다. 경로 탐색·눈부심 모델·교통 데이터 정책은 변경하지 않았다.
- 자동 검사는 모의 GPS·경로·지도 스타일로 동작을 확인한다. 실제 폰 성능·발열·배터리·주행 안전성이나 현실의 교차로 정확도를 입증하지 않는다.

## 실제 폰·주행 확인 — 미실시

1. 기존 앱에서 1.3.19 업데이트 후 즐겨찾기·음성·단위 유지, 안내 시작 시 조감도, 종료 후 2D 미리보기. 2D 선택 후 재실행 시 선호 유지.
2. 익숙한 도로에서 차량 화살표·경로선·실제 도로의 정렬, 주행 방향/북쪽 전환, 두 손가락 확대·회전, 수동 탐색 후 재중앙 정렬.
3. 보스턴 345 Harvard Street → 84 Gerry Road 등에서 실제 교차로·출구·연속 회전과 강조점 비교. 잘못된 차로 정보나 과도한 확대/축소, 다음 회전 가림 여부 기록.
4. 세로·가로 거치, 화면 분할·큰 글꼴에서 안내·도착 정보·버튼·차량이 가리지 않는지 확인. 지도 탐색과 설정 패널 열기/닫기, 화면 회전 중 경로 유지.
5. 저배터리 자동 절전 → 충전 → 일반 모드 수동 복귀. 2D/조감도 선택 유지와 발열·프레임·배터리 사용량을 20~30분 주행으로 비교.
6. PiP·화면 끄기·복귀·앱 전환·전화·블루투스에서 지도 복구와 기존 음성 안내 유지. GPS 불량·터널 출구에서 오래된 회전 강조가 남지 않는지 확인.
7. 통신 끊김·재연결, 지도 서비스 실패, 야간 지도·위성 지도 전환에서 빈 화면이나 반복 깜빡임이 없는지 확인. 타일이 없는 오프라인 지역의 배경 지도 표시를 보장하지 않는다.
8. 실제 주행 중 화면 조작과 기록은 동승자가 수행한다. 기기 성능에 따라 2D를 사용할 수 있다.

## 검증·배포 결과

- Node 단위 검사 318건 통과, 조감도 핵심 브라우저 검사 4건 통과.
- UTC로 고정한 로컬 전체 브라우저 검사 158건 통과. 조감도 교차로 검사는 UTC 환경에서 3회 연속 통과했고, 절전 중 2D/3D 버튼이 실제 화면 상태를 기준으로 요청하는 추가 검사도 통과했다.
- Android JVM 29건 통과, debug APK 빌드 성공, lint 오류 0건·기존 경고 19건.
- npm audit 취약점 0건, root/www 63개 자산 일치, 버전 단조 증가 확인.
- 실제 OpenFreeMap 타일을 사용하는 브라우저 자유 주행 확인: pitch 50°, 지도 객체 286개 렌더링, 지도 요청 32건 HTTP 200, 페이지 오류 0건. 북쪽 고정·가로 화면 전환 확인. GPS는 모의 좌표이므로 실제 주행 검사가 아니다.
- 가로 화면 캡처에서 발견한 출처 표시·차량·하단 요약의 겹침을 수정하고 위치 경계 검사를 추가했다. 벡터 오류 대체 검사는 실제 12초 로딩 제한을 기다리도록 수정한 뒤 통과했다.
- CI에서 조감도 색상 검사의 임시 예보 데이터가 초기 GPS 경로 재계산과 경합하는 문제를 UTC 환경에서 재현했다. 카메라 검사는 분석 결과 경계에서 고정 데이터를 공급하도록 수정했고, 별도의 태양·기상 통합 검사는 유지했다. 브라우저 검사 시간대를 UTC로 고정했다.
- 병렬 CI에서 드러난 벡터 레이어 제거 후 콜백 문제를 수정했다. 제거·재추가 프레임과 이전 moveend의 단위 검사, 실제 브라우저 직접 재현 2건, 절전·PiP·화면 복귀 반복 10건 통과.
- 실제 기기는 ADB에 연결되어 있지 않아 폰 설치·주행 검사는 실시하지 않았다.
- 최종 소스 `af59f73cd91c848c857285238b83fc6feb04afcf`의 [릴리스 CI](https://github.com/HyeokjaeKwon26/Solarless-Navi/actions/runs/40804761644) 검증 단계 통과: Node 318건, 브라우저 160건, Android JVM·debug 빌드·lint 성공, 취약점 0건, 웹 자산 63개 일치.

# 음성 이름·한영 안내 일관성 검증

버전 1.3.18 / versionCode 22. 기존 com.solaris.nav 패키지와 정식 서명키를 유지한다.

## 원인과 변경

기존 목록은 Android TTS가 반환한 voice name을 그대로 표시했다. 한국어 문장의 영문 도로명을 별도 영어 구간으로 합성하므로, 한국어 목소리만 변경하면 도로명에서는 저장된 영어 목소리 또는 영어 기본 목소리로 바뀌었다.

1. 목록에는 고정 별칭, 언어·지역, 기기용/인터넷용을 표시한다. 같은 코드의 local/network 변형은 같은 별칭을 사용하되 연결 조건으로 구분한다. 목록 순서가 달라져도 이름은 바뀌지 않는다. 알려지지 않은 코드에는 엔진 ID 기반 별칭을 사용한다. 읽기 쉬운 엔진 이름은 유지한다.
2. 엔진 제공 품질·응답 등급과 원래 이름을 확인할 수 있다. Android Voice API에는 표준 성별·음색 필드가 없으므로 임의로 ‘남성’, ‘차분함’ 등을 확정하지 않는다. 실제 소리를 듣고 적는 음색 메모는 기기의 localStorage에 저장하며 외부로 보내지 않는다. [Android Voice API](https://developer.android.com/reference/android/speech/tts/Voice).
3. unifiedVoice 기본값을 true로 추가했다. 기존 저장 설정도 선택한 ko/en ID·속도·음높이를 유지하면서 이 기본값을 적용한다. 선택한 안내 언어의 목소리로 전체 문장을 합성하며, 영어 도로명 약어 확장은 유지한다. 같은 화자의 원어민 영어 발음을 보장하는 기능은 아니며, 단일 언어 엔진의 영어 발음에는 제한이 있다.
4. ‘언어별 목소리’를 고르면 기존처럼 한국어/영어 구간을 각각 선택한 목소리로 읽는다. 이 모드의 음색 차이는 UI에서 설명한다. 한국어 미리 듣기에도 Harvard Avenue를 넣어 실제 설정을 비교할 수 있다.
5. 전경과 백그라운드/PiP 모두 Native NavigationSpeech가 저장된 설정으로 음성 계획을 만든다. 웹에서 전달한 원래 언어 구간은 유지하며, 오래된 웹 설정으로 네이티브 설정을 덮어쓰지 않는다. 브라우저 대체 경로에는 같은 계획 규칙을 적용했다.
6. 설정 저장에 성공하면 이전 음성 대기열을 중단하고 안내 단계를 초기화해 다음 GPS 안내에 새 설정을 사용한다. 사용 불가 음성의 기본값 대체 안내, 음소거, 통화·오디오 포커스 정책은 유지한다.

## 자동 검증

- Node: 별칭의 안정성·local/network 구분·품질 정보·없는 정보 처리, 설정 마이그레이션, 선택한 한국어/영어 음성 ID, 한영 통일/분리, 약어 확장·속도·음높이.
- 브라우저: 설정 저장·재실행, 미리 듣기 계획, 별칭/원래 이름 분리, 음색 메모의 안전한 텍스트 표시, 모드 변경, 좁은/가로 화면, 음소거·실패·주행 중 미리 듣기 차단. 네이티브 브리지는 모의하며 실제 소리를 검증하지 않는다.
- Android JVM: SpeechPreferences JSON 왕복·기본값과 SpeechPlan의 통일/분리·백그라운드 거리 접두어. 실제 TTS 엔진의 파형·발음·성별 검증은 아니다.
- 전체 회귀·빌드·배포 결과는 완료 후 아래에 기록한다.

## 실제 폰 확인 — 미실시

1. 기존 정식 앱에서 1.3.18 업데이트. 즐겨찾기·한국어/영어 음성·속도·음높이가 보존되는지 확인한다.
2. 한국어 각 별칭을 미리 듣고 실제 음색을 비교한다. 필요하면 ‘낮은 남성’ 등 메모를 적고 재실행 후 목록에 유지되는지 확인한다. 엔진에 없는 성별·음색을 별칭만으로 판단하지 않는다.
3. 한국어 목소리를 변경한 뒤 ‘한 목소리로 통일’에서 Harvard Avenue·Lee Street가 들어간 미리 듣기와 실제 회전 안내를 비교한다. 중간에 다른 기본 영어 목소리로 전환되지 않는지, 영어 발음이 수용 가능한지 확인한다.
4. ‘언어별 목소리’에서는 지정한 한국어/영어 목소리가 각각 나오는지 비교한다. 영어 안내로 앱 언어를 바꾸면 저장된 영어 목소리가 문장 전체에 적용되는지 확인한다.
5. 안내 직전 설정을 변경했을 때 이전 대기 음성이 멈추고 다음 안내부터 새 목소리로 나오는지 확인한다. PiP 진입·복귀, 화면 끄기·복귀, 차량 블루투스·통화 후 재개에서도 동일 설정을 확인한다.
6. 기기용/인터넷용 음성을 비행기 모드·네트워크 복귀에서 비교한다. 음성 데이터 삭제나 엔진 변경 후 사용 불가 표시와 목록 새로고침을 확인한다.
7. 실제 주행에서는 동승자가 회전 안내 시점·음량·발음·음성 누락을 확인한다. 이번 변경은 실제 엔진·기기에서 소리까지 검증한 결과가 아니다.

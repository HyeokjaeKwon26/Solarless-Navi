NREL SPA·Bird 맑은하늘 기준, Open-Meteo 기상예보와 공개 장면 데이터로 계산한 실험용 추정값입니다. 실제 UV 선량·실내온도·의학적 보호효과가 아닙니다. 경로·기상·장소 조회를 위해 위치, 경로 표본과 검색어가 외부 공개 API로 전송될 수 있습니다.

주행 검토 / Drive review

주행 후 기억을 바탕으로 선택한 지점을 평가합니다. / Review this point after driving.

기기에 최대 200건·90일 보관. 기록 내보내기에 포함됩니다. 자동 업로드 없음. / Up to 200 observations for 90 days, included in recording exports. No automatic upload.

현재 지도 중심 타일을 확인합니다. 저장됨은 모든 건물·높이·나무의 정확성을 보장하지 않습니다. / Checks the center tile. Cached data does not guarantee complete buildings, heights or trees.
